# 🏰 Castle Defender

**Medieval Tower Defense** — стратегическая игра в жанре Tower Defense с средневековым сеттингом.

## 🎮 Описание

Защитите замок от волн врагов, размещая башни различных типов вдоль пути врагов. Используйте стратегию и экономику, чтобы выдержать все 20 волн атак!

## 🚀 Запуск

```bash
cd castle_defender
go run main.go
```

Или запустить скомпилированный бинарник:

```bash
./castle_defender
```

## 🎯 Управление

| Клавиша/Действие | Описание |
|-----------------|----------|
| **1** | Выбрать башню лучников (50 золотых) |
| **2** | Выбрать пушку (100 золотых) |
| **3** | Выбрать магическую башню (150 золотых) |
| **ЛКМ** | Разместить башню |
| **ПКМ** | Отменить выбор |
| **ENTER/SPACE** | Начать игру / Продолжить |

## 🏗️ Типы башен

| Башня | Стоимость | Урон | Скорость | Дальность | Описание |
|-------|-----------|------|----------|-----------|----------|
| 🏹 **Лучник** | 50g | 15 | 25 кадров | 180 | Быстрые выстрелы, средняя дальность |
| 💣 **Пушка** | 100g | 40 | 60 кадров | 150 | Медленные, высокий урон |
| 🔮 **Магия** | 150g | 8 | 10 кадров | 120 | Очень быстрая, низкий урон |

## 👾 Типы врагов

| Враг | HP | Скорость | Награда | Описание |
|------|-----|----------|---------|----------|
| ⚔️ **Рыцарь** | 25+ | 1.0 | 10g | Базовый враг |
| 🏹 **Лучник** | 12+ | 1.5 | 15g | Быстрый, мало HP |
| 🗿 **Гигант** | 75+ | 0.5 | 30g | Медленный, много HP |

## 📊 Игровая механика

### Экономика
- **Стартовое золото:** 150g
- **Награда за врага:** 10-100g (в зависимости от типа)
- **Бонус за волну:** +50g
- **Очки:** Награда × 10

### Волны
- **Всего волн:** 20
- **Врагов в волне:** 5 + (номер_волны × 2)
- **Интервал спавна:** 60 - (номер_волны × 2) кадров

### Жизни
- **Стартовые жизни:** 10
- **Потеря жизни:** Когда враг достигает замка
- **Game Over:** При 0 жизней

## 🎯 Стратегия

1. **Ранняя игра:** Начните с башен лучников — они дешёвые и эффективные
2. **Средняя игра:** Добавьте пушки для борьбы с гигантами
3. **Поздняя игра:** Магические башни для быстрого уничтожения быстрых врагов
4. **Размещение:** Ставьте башни рядом с изгибами пути для максимального времени атаки
5. **Баланс:** Не тратьте всё золото сразу, оставляйте резерв
