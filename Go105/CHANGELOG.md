# 📝 CHANGELOG — Go105: Geometric Match Game

## 2026-04-15

### Инициализация проекта
- Создана структура проекта
- Настроен `go.mod` с зависимостью `github.com/hajimehoshi/ebiten/v2`

### Реализация ядра игры
- `main.go` — точка входа, инициализация Ebitengine (800×600, 60 FPS)
- `board.go` — игровое поле 10×20, коллизии, очистка линий
- `tetromino.go` — 7 типов тетрамино (I, O, T, L, J, S, Z), повороты, цвета
- `game.go` — игровой цикл, состояния (Menu, Playing, Paused, GameOver)

### Управление и UI
- `input.go` — клавиатура (стрелки, пробел, P) + мышь/тач
- `ui.go` — HUD: счёт, уровень, линии, превью следующей фигуры

### Анимации и ассеты
- `animation.go` — тень падения, анимация исчезновения линий, пульсация
- `assets.go` — процедурная генерация спрайтов (без внешних файлов)
- `sounds.go` — процедурные звуковые эффекты (beep)

### Финальные штрихи
- Сохранение рекорда в JSON
- Экран Game Over с кнопкой Restart
- Адаптивная сложность (ускорение каждые 10 линий)
- `index.html` для Web-сборки
