## 🎯 Текущий проект

### 🌸 Kingdom Garden ⭐ NEW!

**Мирная песочница** — создавай красивое королевство!

**Особенности:**
- 🌸 Сажай деревья, цветы, кусты
- 🏰 Строй замки, домики, заборы
- 🦋 Наблюдай за кроликами, птичками, бабочками
- ☁️ Наслаждайся облаками и сменой времени суток
- 🌈 Никаких врагов — только созидание!

**Вдохновение:** Stardew Valley, Animal Crossing, Dorfromantik

**Технологии:**
- Go 1.25
- Ebitengine v2.9.9
- Векторная графика (рисование кодом)

**Запуск:**
```bash
cd dungeon_survivor
go mod tidy
go run main.go
```

**Управление:**
- **WASD / Стрелки** — перемещение
- **E** — посадить растение
- **B** — режим строительства
- **I** — инвентарь
- **ESC** — пауза

**Статус:** Базовая структура ✅ | В разработке 🚧
