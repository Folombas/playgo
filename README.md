## 🎯 Игры в репозитории

### 1. 🌾 Harvest Heroes v3.2 ⭐
**Farm & Dungeon RPG** — Ферма + Подземелья + Животные!

**Особенности:**
- 13 сбалансированных культур с сезонностью
- Регенерирующие культуры (клубника, томаты, виноград)
- Животные (курицы, коровы, овцы)
- Сбор продуктов (яйца, молоко, шерсть)
- Рыбалка (4 рыбы)
- Шахта (4 руды)
- Магическая система (4 заклинания)
- Система романтики и брака
- 4 сезонных фестиваля
- Квесты и достижения

**Баланс культур:**
- Весна: 🍓 Клубника (70¢, 5 дней, регенерирует)
- Лето: 🍅 Томат (60¢, 5 дней, регенерирует)
- Осень: 🎃 Тыква (80¢, 7 дней)
- Зима: ✨ Магия (150¢, 10 дней)

```bash
cd harvest_heroes
go run main.go
```
