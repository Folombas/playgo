## 🎯 Текущий проект

### 🏠 Village Platformer ⭐ NEW!

**Классический 2D-платформер** — беги, прыгай, исследуй деревню!

**Особенности:**
- 🏃 Бег и прыжки по уровню слева направо
- 🏠 Уютные домики с двускатными крышами
- 🏭 Трубы с идущим дымом
- 🌲 Деревья и ёлки (дуб, сосна, берёза)
- ⛰️ Холмы и лужайки
- 💰 Сбор монеток на платформах
- 🚩 Флаг победы в конце уровня
- ☁️ Облака и солнце на небе

**Вдохновение:** Super Mario, классические платформеры

**Технологии:**
- Go 1.25
- Ebitengine v2.9.9
- Векторная графика (рисование кодом)

**Запуск:**
```bash
cd dungeon_survivor
go mod tidy
go run main.go
```

**Управление:**
- **A/D или ←/→** — бег
- **W/↑/SPACE** — прыжок
- **ESC** — пауза

**Статус:** Базовая механика ✅ | В разработке 🚧
