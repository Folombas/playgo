## 🎯 Игры в репозитории

### 1. 🏰 Castle Defender v2.1
**Tower Defense** — Защита замка башнями!

**Особенности:**
- 7 типов башен (лучник, пушка, магия, лёд, снайпер, молния, яд)
- 10 типов врагов с уникальными способностями
- Система улучшений башен (3 уровня)
- Боссы каждые 5 волн
- 30 волн сложности

**Управление:**
- **1-7** — Выбор башни
- **ЛКМ** — Разместить башню
- **U + ЛКМ** — Улучшить башню

```bash
cd castle_defender
go run main.go
```
