
### 🎯 Что реализовано

#### 1. Система спрайтов (`sprite/loader.go`)
- **Loader** с кэшированием - спрайты загружаются один раз
- Поддержка загрузки из относительных путей
- Автоматическое кэширование в `map[string]*ebiten.Image`

#### 2. Система ввода (`input/input.go`)
- **Action-based дизайн** - абстракция над клавишами
- `IsJustPressed` (edge-triggered) vs `IsPressed` (level-triggered)
- Поддержка: A/D, стрелки, W/Up/Space, Escape, R

#### 3. Сущности (`entity/entity.go`)
**Player:**
- Двойной прыжок (MaxJumps=2)
- 5 состояний: Idle, Running, Jumping, Falling, Hurt, Dead
- Анимация ходьбы (11 кадров)
- Физика: гравитация (1000), трение (0.85), ограничение скорости
- Система HP с кадрами неуязвимости (60 фреймов = 1 сек)
- Отражение спрайта по горизонтали (FacingRight)

**Enemy (3 типа):**
- Slime - медленный, патрулирует
- Bat - быстрый, летает
- Snail - медленный, с панцирем
- Patrol AI с автоматическим разворотом
- Анимация (2 кадра)
- Система HP

**Item (5 типов):**
- Coin (+10 очков)
- Gem (+25 очков)
- Star (+100 очков, редкий)
- Heart (лечение +1 HP)
- Key (будущее использование)
- Анимация парения (sinusoidal float)

**Platform:**
- Твёрдые платформы с AABB коллизиями
- Поддержка тайлинга (TileWidth/TileHeight)

#### 4. Генерация уровней (`level/level.go`)
- **Chunk-based система** - каждый чанк 800px шириной
- Процедурная генерация с seed (детерминированная)
- **Элементы чанка:**
  - Земля с 20% шансом ямы (pit)
  - 1-3 плавающих платформы на разной высоте
  - 0-2 врага (шанс зависит от сложности)
  - 2-6 монет
  - 40% шанс гема
  - 20% шанс звезды
  - 15% шанс сердца
- **Прогрессия сложности:**
  - `difficulty` увеличивается с каждым чанком (+0.2)
  - Больше врагов, больше ям

#### 5. Игровой движок (`engine/engine.go`)
**Game States:**
- Menu → Playing → Paused ↔ Playing → GameOver → (Restart) → Playing

**Камера:**
- Плавное следование за игроком (lerp 0.1)
- targetCamX = player.X - 400
- Автогенерация новых чанков при приближении к краю
- Удаление старых чанков (max 10 активных)

**Коллизии:**
- AABB (Axis-Aligned Bounding Box)
- Разрешение по минимальному перекрытию (min overlap)
- 4 направления: top, bottom, left, right

**Бой:**
- Stomp сверху = убийство врага (+50 очков, отскок)
- Боковое касание = урон игроку (1 HP)
- Частицы при ударах

**Частицы:**
- Система частиц с гравитацией
- Цвет, время жизни, затухание альфа-канала
- Спавн при: прыжке, сборе предметов, уроне, убийстве врага

**Фон:**
- Небо (bg.png)
- Параллакс-облака (отключено - нет спрайтов)

#### 6. HUD (`hud/hud.go`)
- Сердца HP (Full/Empty)
- Иконка монеты + счётчик
- Общий счёт (Score)
- Экраны: Menu, Paused, GameOver

### 🐛 Баги, исправленные сегодня
1. **nil pointer dereference** - `loadSprites()` вызывался до создания `g.player`
   - **Фикс:** Переместил `g.player = entity.NewPlayer()` перед `g.loadSprites()`
2. **basicfont.Face7x13.Bounds undefined** - метод Bounds() не существует
   - **Фикс:** Заменил на `len(msg) * 7` (ширина символа = 7px)
3. **Неправильный путь к спрайтам ходьбы** - `p1_walk01.png` vs `p1_walk/PNG/p1_walk01.png`
   - **Фикс:** Добавил подпапку `/PNG/` в путь

10. **Go modules** - `go mod tidy`, зависимости
