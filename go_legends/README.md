# ⚔️ Go Legends

**Roguelike Card Battler** — стратегическая карточная игра в жанре roguelike с элементами deck-building.

## 🎮 Описание

Погрузитесь в эпические карточные сражения! Проходите этажи, побеждайте врагов, собирайте новую колоду и станьте легендой!

## 🚀 Запуск

```bash
cd go_legends
go run main.go
```

Или запустить скомпилированный бинарник:

```bash
./go_legends
```

## 🎯 Управление

| Действие | Управление |
|----------|------------|
| **Выбрать карту** | Клик левой кнопкой мыши |
| **Наведение** | Движение мыши по карте |
| **Завершить ход** | Кнопка "Конец хода" |
| **Настройки** | Кнопка в главном меню |

## 🏗️ Игровая механика

### Боевая система
- **Пошаговые сражения** — планируйте каждый ход
- **Энергия** — ограничивает количество карт за ход
- **Блок** — временно поглощает урон
- **Намерения врага** — предсказывайте действия противника

### Типы карт

| Тип | Иконка | Описание | Примеры |
|-----|--------|----------|---------|
| ⚔️ **Атака** | Красный | Наносит урон врагам | Удар, Огненный шар |
| 🛡️ **Защита** | Синий | Даёт блок | Щит, Неуязвимость |
| ✨ **Бафф** | Зелёный | Усиливает игрока | Боевой клич, Лечение |
| ☠️ **Дебафф** | Фиолетовый | Ослабляет врага | Яд |

### Редкость карт

| Редкость | Цвет | Описание |
|----------|------|----------|
| 📄 **Обычная** | Серый | Базовые карты |
| 🟢 **Необычная** | Зелёный | Улучшенные эффекты |
| 🔵 **Редкая** | Синий | Мощные способности |
| 🟡 **Легендарная** | Золотой | Уникальные карты |

### Прогрессия
- **10 этажей** — каждый сложнее предыдущего
- **5 типов врагов** — Гоблин, Скелет, Орк, Тролль, Дракон
- **Награда за победу** — новая карта в колоду
- **Золото** — будущая валюта для магазинов

## 🛠️ Технологии

- **Язык:** Go 1.25
- **Движок:** Ebitengine v2.9.9
- **Размер окна:** 1280×720 пикселей
- **Шрифты:** SuperFeel
- **Аудио:** Процедурная генерация звуков

## 🎮 Игровые состояния

1. **Главное меню** — начало игры, настройки, выход
2. **Карта** — выбор этажа для прохождения
3. **Бой** — сражение с врагом
4. **Выбор карты** — награда за победу
5. **Настройки** — конфигурация игры
6. **Поражение** — экран game over
7. **Победа** — переход на следующий этаж

## 📖 Советы по игре

1. **Балансируйте колоду** — смесь атаки и защиты
2. **Следите за энергией** — не тратьте всё сразу
3. **Изучайте врагов** — запоминайте намерения
4. **Копите блок** — предотвращайте урон
5. **Улучшайте колоду** — добавляйте редкие карты
