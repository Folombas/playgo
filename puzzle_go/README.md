# Crystal Cascade - Puzzle GO

## 🎮 Match-3 игра на Go + Ebitengine

Красивая и современная игра-головоломка "три в ряд", созданная в рамках годового челленджа **Go365** - изучение Go до продвинутого уровня.

### 🚀 Фичи

- ✨ **Плавные анимации** - 60 FPS с easing функциями
- 💎 **6 типов кристаллов** - красочные игровые элементы
- 🎆 **Система частиц** - впечатляющие эффекты при уничтожении
- 🎵 **Звуковое сопровождение** - BGM и SFX
- 🎯 **Комбо-система** - множитель очков за последовательные совпадения
- 📊 **Система уровней** - прогрессия по мере набора очков
- 🎨 **Современный UI** - красивый интерфейс с тенями и градиентами

### 🛠 Технологии

- **Язык**: Go 1.22+
- **Движок**: [Ebitengine](https://ebiten.org/) (ebiten/v2)
- **Архитектура**: Модульная структура с четким разделением ответственности
- **Паттерны**: Entity-Component, State Machine, Observer

### 📁 Структура проекта

```
puzzle_go/
├── cmd/game/main.go           # Точка входа
├── internal/
│   ├── config/                # Конфигурация и константы
│   ├── entity/                # Игровые сущности (кристаллы)
│   ├── board/                 # Логика игрового поля (Match-3)
│   ├── game/                  # Игровой цикл и состояния
│   ├── render/                # Рендеринг и спрайты
│   ├── ui/                    # Пользовательский интерфейс
│   └── audio/                 # Звуковая система
└── assets/
    ├── sprites/               # Спрайты кристаллов и тайлов
    └── sounds/                # Звуки и музыка
```

### 🎯 Управление

- **Левая кнопка мыши**: Выделение и обмен кристаллов
- **Правая кнопка мыши**: Отмена выделения
- **Цель**: Собрать 3+ одинаковых кристалла в ряд

### 📊 Игровая механика

#### Система очков
- **Базовое совпадение**: 100 очков за каждый кристалл
- **Комбо-множитель**: +50% за каждое последовательное совпадение
- **Каскадные реакции**: Автоматическое падение кристаллов создает новые комбо

#### Специальные элементы (в разработке)
- **4 в ряд**: Бомба (взрывает область 3x3)
- **5 в ряд**: Радужный кристалл (уничтожает все одного типа)
- **L/T форма**: Луч (уничтожает линию)

### 🚀 Запуск

```bash
# Переход в директорию проекта
cd puzzle_go

# Загрузка зависимостей
go mod tidy

# Запуск игры
go run cmd/game/main.go

# Компиляция
go build -o puzzle.exe cmd/game/main.go
```
