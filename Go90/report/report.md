### 2. Полная переработка архитектуры игры

#### Новая компонентная система (ECS-подобная)
**Файл:** `internal/entity/entity.go`

Компоненты:
- **Transform** — позиция, размер, скорость, направление
- **SpriteRenderer** — отрисовка спрайтов с поддержкой анимаций
- **Animator** — управление анимациями (play, loop, frame timing)
- **Physics** — гравитация, трение, коллизии
- **Health** — здоровье, неуязвимость, смерть

Сущности:
- **Player** — игрок с состояниями (idle, run, jump, crouch, shoot, hurt)
- **Enemy** — враги с типами поведения (melee, ranged, flying, patrol)
- **Projectile** — снаряды с физикой и временем жизни
- **Item** — предметы с анимацией парения

#### Система загрузки спрайтов
**Файл:** `internal/sprite/sprite.go`

Реализовано:
- Загрузка спрайтов из PNG файлов
- Поддержка анимаций (walk, swim, fly)
- Автоматическое определение типов врагов и предметов
- Создание фона-заглушки если файл не найден

Использованные спрайты:
- **Player:** p1_stand, p1_walk (11 кадров)
- **Enemies:** fish, fly, slime, snail, blocker
- **Items:** coins, gems, star, mushrooms
- **Tiles:** grass, dirt, brick, box, ladder, door

#### Генерация уровней
**Файл:** `internal/level/level.go`

Функционал:
- Процедурная генерация платформ
- Создание ям и препятствий
- Расстановка врагов по типу уровня
- Генерация предметов с весовой вероятностью
- Названия уровней для атмосферы

#### Система отрисовки
**Файл:** `internal/render/renderer.go`

Возможности:
- Параллакс фон с силуэтами города
- Светящиеся окна в зданиях
- Отрисовка тайлов платформ
- Полоски здоровья врагов
- HUD с здоровьем, патронами, счётом
- Экраны меню, паузы, смерти, победы
- Система частиц для эффектов

#### Игровая логика
**Файл:** `internal/game/game.go`

Состояния игры:
- StateMenu — главное меню
- StatePlaying — игровой процесс
- StatePaused — пауза
- StateGameOver — смерть игрока
- StateVictory — победа
- StateLevelComplete — завершение уровня

Механики:
- Управление игроком (движение, прыжки, стрельба)
- Физика с гравитацией и трением
- Коллизии с платформами
- ИИ врагов (преследование, патрулирование, полёт)
- Сбор предметов с加分
- Система частиц для эффектов

## 🎮 Игровой процесс

### Управление
```
A/D или ←/→ — Бег
W/↑ — Прыжок
S/↓ — Присесть
J — Выстрел
K — Перезарядка
ESC — Пауза/меню
SPACE — Подтверждение
```

### Цель
Пройти 10 уровней, собирая монеты и кристаллы, уничтожая врагов и добравшись до точки эвакуации.

### Особенности
- 5 типов врагов с разным поведением
- 7+ типов предметов
- Процедурная генерация каждого уровня
- Система частиц для эффектов
- Параллакс фон с городом

## 💭 Рефлексия дня

Сегодня был продуктивный день полной переработки игры. Основная цель — 
отказаться от "программных" спрайтов (прямоугольников) и использовать реальные 
PNG-файлы из папки assets/. 

**Главное достижение:** компонентная архитектура, которая позволит легко 
добавлять новые типы сущностей без переписывания кода.

**Сложности:** 
- Настройка путей к спрайтам (папки PNG/default)
- Исправление ошибок компиляции (несоответствие типов)

**Вывод:** Компонентный подход значительно упрощает расширение игры. 
Теперь можно добавлять новые типы врагов, предметов и способностей 
минимальными изменениями кода.
