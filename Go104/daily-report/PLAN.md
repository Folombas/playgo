# Go104 - Match-3 Game (14 апреля 2026)

## 📋 План работ

### Цель
Создать казуальную карманную игру "Три в ряд" (Match-3) на Go с использованием Ebitengine.

### ✅ Выполнено

#### Коммит 1: Инициализация проекта
- Создана структура проекта
- Инициализирован Go модуль
- Добавлен Ebitengine v2.9.9
- Скопированы спрайты из `sprites/puzzle/` (jewel*.png → tile_0.png ... tile_5.png)

#### Коммит 2: assets.go
- Реализована загрузка спрайтов через `go:embed`
- Добавлен fallback на цветные прямоугольники при отсутствии спрайтов
- Встроение 6 спрайтов фишек

#### Коммит 3: board.go
- Реализована логика игрового поля 8×8
- Структуры `Position`, `Tile`, `Board`
- Генерация поля без начальных совпадений (`fillWithoutMatches`)
- Обмен фишек (`Swap`)
- Поиск совпадений (`FindMatches`) - горизонталь и вертикаль
- Удаление фишек с подсчётом очков (`RemoveTiles`)
- Бонусы за 4+ фишек: +50 за 4, +100 за 5+
- Падение новых фишек (`DropTiles`)
- Проверка валидных ходов (`HasValidMoves`)
- Поиск подсказки (`FindHint`)

#### Коммит 4: animation.go
- Система анимаций с `AnimationManager`
- 5 типов анимаций:
  - `AnimSwap` - обмен фишек (200мс)
  - `AnimShake` - дрожание при ошибке (150мс, 3 цикла)
  - `AnimRemove` - удаление с уменьшением масштаба (150мс)
  - `AnimDrop` - падение фишек (200мс, easeOutQuad)
  - `AnimHintPulse` - пульсация подсказки (2с)
- Плавные анимации с использованием `math.Sin`

#### Коммит 5: input.go
- Обработка мыши и тачскрина
- Конвертация экранных координат в координаты сетки
- Проверка клика на кнопку "Новая игра"
- Горячие клавиши: R (сброс), P (пауза)

#### Коммит 6: ui.go
- Отрисовка игрового поля с чередующимися ячейками
- Отрисовка фишек с масштабированием и прозрачностью
- Подсветка выбранной фишки жёлтой обводкой
- Индикаторы счёта и таймера
- Кнопка "Новая игра"
- Экран Game Over
- Экран паузы
- Зелёная обводка подсказки

#### Коммит 7: game.go
- Основной игровой цикл (`Update`, `Draw`, `Layout`)
- Таймер на 60 секунд
- Обработка ввода (мышь + клавиатура)
- Логика выбора и обмена фишек
- Каскадное разрешение совпадений
- Система подсказок (через 5 секунд бездействия)
- Перегенерация поля при отсутствии ходов
- Сохранение/загрузка рекордов (заглушка)

#### Коммит 8: main.go
- Точка входа в игру
- Инициализация Ebitengine
- Настройка окна 800×800
- Загрузка спрайтов
- Инструкция по сборке для Windows/Android/Web

#### Коммит 9: Исправление ошибок
- Исправлены все ошибки компиляции
- Упрощён текст в UI (заглушка для шрифта)
- Исправлен API для анимаций
- Исправлена обработка тачскрина

#### Коммит 10: Финализация

- Проект готов к запуску
