## 🎮 Геймплей

### Главный герой: Солнышко ☀️

**Характеристики:**
- Здоровье: 100 HP
- Свет (энергия): 100
- Двойной прыжок!
- Размер: меняется от грибов

**Способности:**
1. **Лучик света (J)** — стреляет жёлтым лучом, тратит 10 света
2. **Обнимашки (K)** — лечит друзей, восстанавливает здоровье
3. **Двойной прыжок** — можно прыгнуть в воздухе второй раз!

**Механика света:**
- Свет тратится на выстрелы
- Свет восстанавливается сам (10/сек)
- Звёзды полностью восстанавливают свет

### 🦹 Враги (превращаются в друзей)

| Враг | Описание | Тактика |
|------|----------|---------|
| 🌬️ **Ветерок** | Голубой, летает | Лучиками света |
| ⛈️ **Тучка** | Тёмная, метает молнии | Прыгать выше |

- Превращённый враг становится розовым и добрым!

## 🛠️ Технические детали

### Архитектура (ECS)

**Компоненты:**
- **Transform** — позиция, размер, скорость, направление
- **Physics** — гравитация (1000), трение (0.85), ускорение
- **Health** — здоровье, неуязвимость (2 сек)
- **Light** — солнечная энергия, регенерация
- **SpriteRenderer** — отрисовка спрайтов
- **Animator** — анимации (loop, single-shot)

**Сущности:**
- **Player** — Солнышко (игрок)
- **Friend** — друг (пчёлка, божья коровка, и т.д.)
- **Enemy** — враг (ветерок, тучка, и т.д.)
- **Projectile** — лучик света
- **Item** — предмет (монеты, кристаллы, грибы)
- **Cloud** — облачко (коллекционный предмет)

### Процедурная генерация уровней

1. **Террейн:** Пол с ямами (1-5 ям на уровень)
2. **Платформы:** 4+level*2 случайных платформ
3. **Лестницы:** 1+level/2 для вертикального перемещения
4. **Враги:** 2+level*2, типы зависят от уровня
5. **Друзья:** 3+level, милые существа
6. **Облачка:** 3+level/2 для сбора
7. **Предметы:** 6+level*2 с весами редкости

### Рендеринг

**Фон:**
- Градиентное небо (голубой → розовый)
- Солнышко на фоне с лучиками
- Пушистые облака (3 типа)
- Зелёные холмы (параллакс)

**Платформы:**
- 🌿 Трава: коричневая с зелёной верхушкой и цветочками
- 🍄 Грибы: коричневые с красными точками
- 🏰 Замок: розовые кирпичики
- 🍬 Конфеты: розово-белые полоски
- ❄️ Лёд: голубой полупрозрачный
- 🪜 Лестницы: деревянные перекладины

**Игрок (Солнышко):**
- Жёлтый круг с градиентом
- Лицо с глазками и улыбкой! 😊
- Лучики вокруг (8 штук, вращаются)
- Мигание при неуязвимости

**Враги:**
- Цвет зависит от типа
- Превращённые = розовые с улыбкой!
- Глазки для направления

**Выход:**
- Флагшток с зелёным флагом
- Звёздочка на флаге
- Мигающий золотой шар сверху

**Частицы:**
- При сборе предметов
- При выстрелах
- При обнимашках
- При превращении врагов

### UI/HUD

## 🎯 Управление в игре

| Клавиша | Действие |
|---------|----------|
| **A / ←** | Бежать влево |
| **D / →** | Бежать вправо |
| **W / ↑ / Пробел** | Прыжок (двойной в воздухе!) |
| **S / ↓** | Присесть / спуститься |
| **J** | Бросить лучик света ☀️ |
| **K** | Обнять друга 💕 |
| **ESC** | Пауза / меню |
