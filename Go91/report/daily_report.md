**🎮 Новая концепция: "Cyber City Runner"**

**Сеттинг:** Неоновый киберпанк-город 2077 года. Вы — хакер-беглец, укравший данные у мегакорпорации.

**Ключевые изменения в геймдизайне:**

1. **3 класса персонажей:**
   - 👨‍💻 **Хакер** - сбалансированный, способность "Взлом"
   - 🤖 **Робот** - танк с щитом, больше здоровья, медленнее
   - 🥷 **Ниндзя** - быстрый и ловкий, способность "Невидимость"

2. **Новые механики:**
   - **Двойной прыжок** - можно прыгнуть в воздухе второй раз
   - **Рывок (Dash)** - короткое ускорение, расходует энергию
   - **Система комбо** - чем больше собираете без урона, тем больше очков
   - **Восстановление энергии** - энергия для рывка восстанавливается со временем

3. **4 типа врагов:**
   -  **Дрон** - летает, стреляет лазерами
   -  **Робопёс** - патрулирует зону, быстрый
   - 🔫 **Турель** - статичная, стреляет при приближении
   - 📷 **Камера** - обнаруживает, поднимает тревогу

4. **10 уровней с прогрессией:**
   - Трущобы → Промышленная зона → Нижний город → Средний уровень → Торговый квартал → Деловой центр → Научный комплекс → Военная база → Небоскрёбы → Крыша корпорации

## 🛠️ Технические детали реализации

### Компонентная архитектура (ECS)

**Transform:**
- Позиция (X, Y)
- Размер (Width, Height)
- Скорость (VX, VY)
- Направление (Facing)

**Physics:**
- Гравитация (1200)
- Трение (0.85)
- Ускорение (800)
- Проверка на земле ли (OnGround)

**Health:**
- Текущее/макс. здоровье
- Таймер неуязвимости
- Лечение и урон

**SpriteRenderer:**
- Отрисовка спрайтов
- Поддержка анимаций
- Отражение по горизонтали

**Animator:**
- Управление анимациями
- Loop и single-shot режимы

### Игровая логика

**Player:**
- Движение (A/D или ←/→)
- Прыжок (W/↑/Пробел) с поддержкой двойного
- Рывок (Shift) - расходует энергию
- Стрельба (J)
- Специальная способность (K)

**Enemy AI:**
- **Melee** - преследование игрока
- **Flying** - плавное движение к игроку
- **Patrol** - патрулирование + преследование
- **Turret** - статичная, только стрельба
- **Camera** - только обнаружение

### Процедурная генерация уровней

1. **Террейн:** Пол с ямами (количество ям растёт с уровнем)
2. **Платформы:** Случайные платформы разной ширины
3. **Лестницы:** Вертикальное перемещение
4. **Враги:** Размещение в зависимости от типа уровня
5. **Предметы:** Монеты, кристаллы, аптечки с весами редкости

### Рендеринг

- **Фон:** Тёмно-фиолетовый с неоновыми линиями
- **Платформы:** Разные цвета для типов (земля, трава, кирпич, коробки)
- **Игрок:** Неоновый прямоугольник с "глазами"
- **Враги:** Цвета по типам (красный, оранжевый, синий, жёлтый)
- **Предметы:** Светящиеся круги
- **Выход:** Неоновый портал с миганием
- **Частицы:** При сборе предметов, выстрелах, рывке

### UI/HUD

- Полоска здоровья (красная/жёлтая/зелёная)
- Полоска энергии (циан)
- Счёт
- Номер и название уровня
- Комбо-множитель
- Специальная способность
