# Go Platformer 2D - Mario Style Game

## Project Created Successfully ✅

### Folder Structure:
```
GoPlatformer2D/
├── main.go              # Game entry point with ECS architecture
├── sprite_loader.go     # Sprite loading system
├── ai.go               # Enemy AI (patrol & chase)
├── package.json        # Project configuration
├── run.bat             # Build/run script
├── sprites/            # ✅ Contains 100+ assets including:
│   ├── Players/        # Mario, enemy characters
│   ├── Tiles/          # Platforms, blocks, decorations
│   ├── Items/          # Coins, flags, keys, gems
│   ├── HUD/            # UI elements
│   └── Particle/       # Visual effects
└── README.md           # Documentation
```

### Game Features:
- **Player Movement**: Left/Right + Jump controls
- **Physics**: Dynamic bodies, collision detection
- **Enemy AI**: Patrol and chase behaviors
- **Sprite System**: Load sprites from `sprites/` folder
- **Level System**: Configurable levels with entities

### Sprite Assets Available:
- Players (128x256 in various colors)
- Tiles (platforms, bricks, ladders, switches)
- Items (coins, flags, keys, gems, bombs)
- HUD elements (hearts, keys, coins)
- Enemy characters (slime, snail, fly, fish)
- And many more!

### To Run:
```bash
# Navigate to the folder
cd GoPlatformer2D

# You'll need to set up the paygo dependency first

```
