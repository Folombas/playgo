### Игровые механики
1. **Игровое поле** - сетка 13x11 тайлов (64x64px каждый)
2. **Стены**:
   - Неразрушаемые (камень) - классическая сетка через каждые 2 клетки
   - Разрушаемые (кирпич) - случайная генерация с 30% шансом
3. **Игрок (Bomberman)**:
   - Движение WASD/стрелки с плавной анимацией
   - 2-кадровая анимация ходьбы
   - 4 направления с отражением спрайта
   - Коллизии со стенами и бомбами (AABB)
   - 3 жизни
4. **Бомбы**:
   - Установка по SPACE
   - Таймер 2 секунды
   - Анимация пульсации
   - Расчет клеток взрыва
   - Callback при детонации
5. **Взрывы**:
   - Крестообразная форма (4 направления)
   - Радиус 2 клетки (настраиваемый)
   - Разрушение кирпичных стен
   - 3-кадровая анимация затухания
   - Урон игроку и врагам
6. **Враги**:
   - 3 AI-врага (slime)
   - Случайное движение с изменением направления
   - Коллизии со стенами
   - 2-кадровая анимация
   - Система смерти
7. **UI**:
   - Главное меню с инструкцией
   - HUD: Lives, Bombs, Fire radius, Enemies count
   - FPS счетчик
   - Перезапуск по R

### Технические решения
- **Ebitengine v2.6.5** - 2D game engine для Go
- **Scene pattern** - разделение на menu/gameplay сцены
- **Entity-component** - каждая сущность独立ный компонент
- **Grid-based collision** - оптимизированные коллизии по сетке
- **Tilemap rendering** - эффективный рендеринг тайлов
- **basicfont** - встроенный шрифт для текста

## 🐛 Проблемы и решения

### 1. Ebitengine text API
**Проблема**: В v2.6.5 нет `ebiten.Font` и `ebiten.NewFontFace`
**Решение**: Использован `golang.org/x/image/font/basicfont` с `font.Face` интерфейсом

### 2. Collision detection
**Проблема**: Игрок застревал в стенах
**Решение**: Реализован AABB с 4 углами хитбокса и sliding collision

### 3. Бомбы блокируют игрока
**Проблема**: Игрок не мог выйти с клетки бомбы
**Решение**: Добавлена логика "можно выйти, нельзя войти"
