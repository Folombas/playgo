# 🚀 Space Empire

**4X Space Strategy** — космическая стратегия в реальном времени с исследованием, экономикой и захватом галактики!

## 🎮 Описание

Постройте свою космическую империю! Исследуйте галактику, захватывайте планеты, развивайте экономику, создавайте флот и уничтожьте вражеские империи!

## 🚀 Запуск

```bash
cd space_empire
go run main.go
```

Или запустить скомпилированный бинарник:

```bash
./space_empire
```

## 🎯 Управление

| Действие | Управление |
|----------|------------|
| **Камера** | Средняя кнопка мыши / Space + движение |
| **Зум** | Колёсико мыши |
| **Выбор планеты** | ЛКМ по планете |
| **Постройка** | Кнопки на панели планеты |
| **Конец хода** | Кнопка вверху справа |
| **Меню** | ESC или кнопка "Назад" |
