## 🎯 Цели на сегодня

### Основная задача
**Полная переработка go_mario** — начинаем с чистого листа, используя новые спрайты из mario_sprites

### Основные направления
1. **Новая архитектура** — чистый код с нуля
2. **Спрайты Марио** — использование классических спрайтов из zip-архивов
3. **Улучшенная физика** — более отзывчивое управление
4. **Визуальные эффекты** — частицы, анимации, параллакс

## 📋 План работ

### 1. Подготовка ассетов
- [ ] Распаковать mario_sprites (11 zip-архивов)
- [ ] Выбрать спрайты Марио (классический красный/зелёный)
- [ ] Выбрать спрайты врагов (Гумба, Купа, Пирания)
- [ ] Выбрать тайлы (кирпичи, блоки, трубы)
- [ ] Выбрать предметы (монеты, грибы, цветы)

### 2. Базовая структура игры
- [ ] Главный цикл игры (Update/Draw)
- [ ] Система состояний (Меню, Игра, Пауза, Game Over)
- [ ] Загрузка и кэширование спрайтов
- [ ] Система координат и камера

### 3. Игрок (Марио)
- [ ] Структура Player с полями: x, y, vx, vy, состояние
- [ ] Физика: гравитация, прыжки, коллизии
- [ ] Анимации: стояние, бег, прыжок, приседание
- [ ] Управление: стрелки/WASD, пробел для прыжка

### 4. Уровень и тайлы
- [ ] Система тайлов (16x16 или 32x32)
- [ ] Генерация уровня (платформы, трубы, ямы)
- [ ] Коллизии с тайлами
- [ ] Декорации (облака, кусты, флаги)

### 5. Враги
- [ ] Базовый класс Enemy
- [ ] Гумба (ходит влево-вправо)
- [ ] Купа (черепашка, прячется в панцирь)
- [ ] Пирания (вылезает из трубы)
- [ ] ИИ врагов и паттерны движения

### 6. Предметы и бонусы
- [ ] Монеты (анимация вращения)
- [ ] Гриб (увеличивает Марио)
- [ ] Цветок (стрельба фаерболами)
- [ ] 1-Up (дополнительная жизнь)
- [ ] Звезда (неуязвимость)

### 7. Интерфейс
- [ ] HUD: очки, монеты, жизни, время
- [ ] Экран меню
- [ ] Экран победы/поражения
- [ ] Счётчики и прогресс

### 8. Аудио
- [ ] Фоновая музыка
- [ ] Звуковые эффекты (прыжок, монета, враг)
- [ ] Система воспроизведения

### 9. Финализация

- [ ] Обновление README.md
