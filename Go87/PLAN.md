# Go365 - День 87 (27 марта 2026)

## 🎯 Цель дня
Полная переработка игры **go_mario** - создание классического платформера Mario на Go + Ebitengine с нуля.

## 📋 План работ

### 1. Организация ассетов
- [ ] Рассортировать спрайты из `sprites/` по тематическим папкам в `go_mario/assets/`
- [ ] Структура:
  - `assets/sprites/mario/` - спрайты Марио
  - `assets/sprites/enemies/` - враги (Гумба, Купа, и др.)
  - `assets/sprites/tiles/` - тайлы уровня
  - `assets/sprites/items/` - предметы (монеты, грибы, цветы)
  - `assets/sprites/decorations/` - декорации
  - `assets/sprites/backgrounds/` - фоны
  - `assets/fonts/` - шрифты
  - `assets/audio/` - звуки

### 2. Базовая структура проекта
- [ ] `main.go` - точка входа
- [ ] `internal/game/game.go` - игровая логика
- [ ] `internal/player/player.go` - игрок
- [ ] `internal/level/level.go` - генерация уровня
- [ ] `internal/assets/assets.go` - загрузка ассетов

### 3. Реализация
- [ ] Игрок с анимациями (стояние, бег, прыжок)
- [ ] Физика платформы (гравитация, коллизии)
- [ ] Система тайлов для уровня
- [ ] Враги с простым AI
- [ ] Собираемые предметы
- [ ] UI (жизни, монеты, счёт)

## 🎮 Геймдизайн

### Игрок
- Движение влево/вправо
- Прыжок (выше при зажатии)
- Анимации: idle, run, jump
- Жизни: 3
- Счётчик монет

### Враги
- Гумба - ходит туда-сюда
- Купа - патрулирует
- При прыжке сверху - враг умирает
- При касании сбоку - игрок теряет жизнь

### Уровень
- Платформы из блоков
- Трубы
- Монеты для сбора
- Флаг в конце уровня

## 📝 Примечания
- Использовать Ebitengine v2
- Фокус на чистом коде и архитектуре
- Комментировать ключевые решения
