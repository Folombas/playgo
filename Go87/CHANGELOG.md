## 🎮 НОВОЕ: go_mario v7.0.0

### Что добавлено

#### 1. БОССЫ 👹
- **Структура Boss:**
  - health/maxHealth (200 + world*100)
  - phase (1 или 2 при 50% HP)
  - attackTimer, attackType
  - 3 паттерна атаки:
    - 📤 Projectile — выстрел в игрока
    - 💨 Charge — рывок к игроку
    - 🦘 Jump — высокий прыжок

- **ИИ босса:**
  - Движение к игроку
  - Прыжки с гравитацией
  - Атаки каждые 60 кадров
  - Ускорение атак в фазе 2

- **Бой с боссом:**
  - Можно прыгать сверху (20 урона)
  - Босс наносит 20 урона
  - Отскок при получении урона
  - Полоска здоровья над ареной

#### 2. СИСТЕМА МИРОВ 🗺️
```
World 1:
  Level 1 → Level 2 → Level 3 → BOSS

World 2:
  Level 1 → Level 2 → Level 3 → BOSS

World 3:
  Level 1 → Level 2 → Level 3 → BOSS

Victory!
```

- **MaxWorld = 3**
- **LevelsPerWorld = 3**
- Лечение между уровнями
- Прогрессия сложности

#### 3. СОХРАНЕНИЯ 💾
```go
type SaveData struct {
    World, Level int
    Health, MaxHealth int
    Coins, Gems, Score int
    Lives int
}
```

- **Сохранение:** Клавиша **S**
- **Загрузка:** Автоматически при старте
- **Формат:** JSON (savegame.json)
- **Данные:** мир, уровень, статы игрока

#### 4. УЛУЧШЕНИЯ UI
- Отображение **World X-Y** в HUD
- Подсказка **[S] Save**
- Полоска HP босса
- Анимированный флаг (мигает)

```
← → / A D      — Бег
```

### Босс Файт

2. **Прыгай сверху** для урона (20 HP)
3. **Фаза 2** (50% HP) — атаки быстрее
4. **Победа** → следующий мир!
