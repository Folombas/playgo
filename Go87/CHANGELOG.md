# Go365 - День 87 (27 марта 2026)

## 🎯 Цель дня
Полная переработка игры **go_mario** - создание классического платформера Mario на Go + Ebitengine с нуля.

## ✅ Выполнено

### 1. Организация ассетов
- ✅ Создана структура папок в `go_mario/assets/`
- ✅ Скопированы спрайты из Platformer Complete Pack:
  - `sprites/mario/` - 7 файлов (стоит, идёт, прыжок, утка, урон)
  - `sprites/enemies/` - 6 файлов (slime, fly)
  - `sprites/tiles/` - 56 файлов (трава, земля, кирпичи, блоки)
  - `sprites/items/` - 17 файлов (монеты, грибы, звёзды, флаги)
  - `sprites/decorations/` - 6 файлов (облака, кусты, растения)
  - `sprites/backgrounds/` - 1 файл (фон)

### 2. Архитектура проекта
Создана модульная структура:
```
go_mario/
├── main.go                     # Точка входа
├── internal/
│   ├── assets/assets.go        # Загрузка ассетов
│   ├── player/player.go        # Игрок с физикой
│   ├── level/level.go          # Генерация уровня
│   └── game/game.go            # Игровая логика
└── assets/sprites/             # Все спрайты
```

- ✅ Управление: стрелки/WASD + пробел/W

## 🎮 Как запустить

```bash
cd go_mario
go run main.go
```

Или запустить готовый exe:
```bash
go_mario.exe
```

### Управление
- **Стрелки / WASD** - движение
- **Пробел / W** - прыжок
- **S / Вниз** - приседание
- **Enter** - выбор в меню
