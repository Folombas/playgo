# 🏙️ City Survivor - Постапокалиптический платформер на Go

**2D платформер в стиле постапокалиптического выживания на Go + Ebitengine**

---

## 📖 Описание

Вы — последний выживший в разрушенном городе после катастрофы. Ваша задача — 
добраться до точки эвакуации, преодолевая разрушенные здания, сражаясь с 
мутантами и собирая припасы.

**Go365 Challenge** — День 90 из 365 🐍

- Пройти все 10 уровней
- Собрать все монеты и кристаллы

- Добраться до точки эвакуации (🚁)

## 🏗️ Уровни

1. **Окраины города** — Обучение, простые враги
2. **Заброшенный район** — Больше предметов
3. **Промышленная зона** — Летающие враги
4. **Центральные улицы** — Смешанные типы врагов
5. **Метрополитен** — Темнота, узкие проходы
6. **Подземный бункер** — Лабиринт
7. **Крыши небоскрёбов** — Опасные падения
8. **Военная база** — Много врагов
9. **Зона отчуждения** — Сложные платформы
10. **Точка эвакуации** — Финал

## 🛠️ Архитектура проекта

```
city_platformer/
├── cmd/
│   └── game/
│       └── main.go              # Точка входа
├── internal/
│   ├── game/
│   │   └── game.go              # Игровая логика, состояния
│   ├── entity/
│   │   └── entity.go            # Компонентная система (ECS)
│   │                            # - Transform, Physics, Health
│   │                            # - Player, Enemy, Projectile, Item
│   ├── level/
│   │   └── level.go             # Генерация уровней
│   │                            # - Процедурная генерация
│   │                            # - Платформы, враги, предметы
│   ├── render/
│   │   └── renderer.go          # Отрисовка
│   │                            # - Параллакс фон
│   │                            # - Частицы, эффекты
│   └── sprite/
│       └── sprite.go            # Загрузка спрайтов
│                                # - Анимации
│                                # - Атласы
├── assets/
│   ├── Player/                  # Спрайты игрока
│   ├── Enemies/                 # Спрайты врагов
│   ├── Items/                   # Предметы
│   ├── Food/                    # Еда/лечение
│   └── Tiles/                   # Тайлы для уровней
├── go.mod
└── README.md
```

## 🎮 Особенности реализации

### Компонентная архитектура (ECS-подобная)
- **Transform** — позиция, размер, скорость
- **Physics** — гравитация, трение, коллизии
- **Health** — здоровье, неуязвимость
- **SpriteRenderer** — отрисовка спрайтов
- **Animator** — управление анимациями

### Процедурная генерация уровней
- Случайные платформы и ямы
- Расстановка врагов и предметов
- Увеличение сложности с каждым уровнем

### Система анимаций
- Покадровая анимация
- Плавные переходы между состояниями
- Поддержка loop и single-shot анимаций

### Параллакс фон
- Многослойный город на заднем плане
- Светящиеся окна зданий
- Атмосферное освещение
