# 🏙️ City Platformer - Last Survivor

**2D платформер в постапокалиптическом городе на Go + Ebitengine**

---

## 📖 Описание

Вы — последний выживший в разрушенном городе после катастрофы. Ваша задача — 
добраться до точки эвакуации, преодолевая разрушенные здания, сражаясь с 
мутантами и роботами-охранниками, собирая припасы.

---

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| **A / ←** | Бег влево |
| **D / →** | Бег вправо |
| **W / ↑** | Прыжок |
| **S / ↓** | Присесть / укрытие |
| **J** | Выстрел |
| **K** | Перезарядка |
| **ESC** | Пауза / меню |
| **SPACE** | Подтверждение / старт |

---

## 🎯 Цель игры

- Пройти все уровни
- Собрать все припасы
- Уничтожить всех врагов
- Добраться до точки эвакуации

---

## 👾 Враги

| Тип | Описание | Тактика |
|-----|----------|---------|
| **Мутант** 🧟 | Медленный, ближний бой | Держать дистанцию |
| **Робот** 🤖 | Стреляет на расстоянии | Прятаться за укрытиями |
| **Зомби** 🧟‍♂️ | Медленный, преследует | Быстро убить |

---

## 📦 Предметы

| Тип | Эффект |
|-----|--------|
| **Аптечка** ❤️ | +25 здоровья |
| **Патроны** 🔫 | +20 патронов |
| **Еда** 🍖 | +10 здоровья |
| **Детали** ⚙️ | +50 очков |

---

## 🏗️ Уровни

1. **Разрушенная улица** — Обучение, простые враги
2. **Заброшенный завод** — Много укрытий, роботы
3. **Тоннель метро** — Темно, зомби
4. **Крыша небоскрёба** — Финал, босс

---

## 🚀 Запуск

```bash
cd city_platformer
go run cmd/game/main.go
```

---

## 🛠️ Требования

- Go 1.25+
- Ebitengine v2.8+
