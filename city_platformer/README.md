# 🏙️ City Platformer - PMC Contractor

**2D платформер в городе с PMC контрактником**

---

## 🎮 Описание

**City Platformer** — это 2D платформер где ты играешь за PMC контрактника с автоматом в городе!

**Особенности:**
- 🪖 **PMC Contractor** — главный герой с автоматом
- 🏙️ **City Mega Pack** — городской фон и здания
- 🌲 **Pine Trees** — сосны и деревья
- 💰 **Сбор монет** — набирай очки
- 🏗️ **Платформы** — прыгай по зданиям и платформам

---

## 🚀 Запуск

```bash
cd city_platformer
go mod tidy
go run main.go
```

---

## 🎯 Управление

| Клавиша | Действие |
|---------|----------|
| **A/D** или **←/→** | Бег влево/вправо |
| **W/↑/SPACE** | Прыжок |
| **ESC** | Пауза / Выход |

## 🎨 Используемые спрайты
