## 📖 Описание

**2087 год. Нео-Токио.**

Вы — **KAI**, элитный хакер-беглец, укравший данные у мегакорпорации **Zaibatsu Corp**.

Ваша задача:
- Сбежать из нижних уровней города
- Взломать контрольные точки
- Избегать корпоративных солдат и дронов
- Добраться до зоны эвакуации

> **"Выживай любой ценой. Доверяй только коду."**

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| **A / ←** | Бежать влево |
| **D / →** | Бежать вправо |
| **W / ↑ / Пробел** | Прыжок (двойной!) |
| **K** | Рывок (dash) |
| **J** | Выстрел из энерго-пистолета |
| **E** | Взлом терминала |
| **Q** | EMP-импульс (оглушает врагов) |
| **L** | Бросить гранату |
| **ESC** | Пауза / меню |

## 🌟 Игровая механика

### 🏃 Паркур-система:
- **Двойной прыжок** — прыгайте в воздухе второй раз
- **Стена-ран** — отталкивайтесь от стен вертикально
- **Рывок (dash)** — быстрый рывок вперёд (тратит энергию)

### 💻 Хакерство:
- **Взлом терминалов** — подходите к терминалам и нажимайте E
- **Отключение турелей** — взламывайте турели
- **Открытие дверей** — некоторые двери требуют взлома

### 👤 Стелс:
- **Тени** — прячьтесь в тени для снижения видимости
- **Шум** — прыжки и выстрелы создают шум, привлекающий врагов
- **Индикатор видимости** — следите за видимостью

### 🔫 Бой:
- **Энерго-пистолет** — бесконечные патроны
- **Гранаты** — ограничены, большой урон
- **EMP-импульс** — оглушает всех врагов в радиусе

## 👾 Враги и ИИ

| Враг | Описание | Тактика |
|------|----------|---------|
| **🤖 Солдат** | Патрулирует, стреляет при обнаружении | Стелс или бой |
| **🛸 Дрон** | Летает, обнаруживает игрока | Уничтожить первым |
| **🔫 Турель** | Стреляет при обнаружении | Взломать или уничтожить |
| **🤖 Робот** | Быстрый, ближний бой | Держать дистанцию |
| **💀 Элитный** | Броня, высокий урон | Только бой |

### Система тревоги:
- Враги обнаруживают игрока в радиусе видимости
- Тревога растёт от шума (выстрелы, прыжки)
- Высокая тревога = больше врагов патрулируют
- EMP снижает тревогу

## 🎨 Визуальный стиль

### Цветовая палитра:
- **Тёмно-синий/фиолетовый** фон (ночной город)
- **Неоновый голубой** (#00FFFF) — интерфейсы, энергия, игрок
- **Неоновый розовый** (#FF00FF) — опасности, враги
- **Неоновый зелёный** (#00FF00) — хакерство, данные
- **Оранжевый** (#FFA500) — взрывы, частицы

### Процедурная графика:
- Все спрайты рисуются кодом (векторная графика)
- Неоновые обводки и эффекты
- Параллакс-фон с городом
- Система частиц

### ECS (Component-Entity-System):

**Компоненты:**
- `Transform` — позиция, размер, скорость
- `Physics` — гравитация, коллизии, трение
- `Health` — здоровье, броня, неуязвимость
- `Energy` — энергия для способностей
- `Stealth` — видимость, шум, тени
- `Hacker` — уровень взлома, таймер

**Сущности:**
- `Player` — KAI (игрок)
- `Enemy` — враги с ИИ (солдаты, дроны, турели)
- `Item` — предметы
- `Projectile` — снаряды
- `Particle` — эффекты
