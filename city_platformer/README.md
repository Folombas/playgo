# 🌈 Sunny Adventure: Приключения Солнышка

**Добрый 2D платформер в стиле сказочного приключения на Go + Ebitengine**

**Go365 Challenge** — День 93 из 365 🐍

---

## 📖 Описание

Милый солнышко ☀️ проснулось утром и обнаружило, что его друзья-облачка ☁️ разлетелись по всему королевству! Злой ветер разбросал их по разным землям.

**Ваша задача** — собрать всех друзей-облачков, победить злого ветра и вернуть радость в небесное королевство!

---

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| **A / ←** | Бежать влево |
| **D / →** | Бежать вправо |
| **W / ↑ / Пробел** | Прыжок (можно прыгать в воздухе!) |
| **J** | Бросить лучик света ☀️ |
| **ESC** | Пауза / меню |

---

## 🌟 Главная механика: Лучики света!

Вы — **Солнышко**! Ваша энергия — это **свет**!

- **Свет тратится** на выстрелы лучиками
- **Свет восстанавливается** со временем
- **Собирайте звёзды** для полной энергии!

## 👾 Друзья и Враги

### 🐛 Милые существа (можно собрать!):
| Существо | Описание |
|----------|----------|
| **Пчёлка 🐝** | Летает, собирает нектар |
| **Божья коровка 🐞** | Ползает по травке |
| **Лягушонок 🐸** | Прыгает по кувшинкам |
| **Улитка 🐌** | Медленная, но мудрая |
| **Призрачок 👻** | Дружелюбный дух |

### 🦹 Злые существа (можно превратить в друзей!):
| Существо | Описание | Тактика |
|----------|----------|---------|
| **Ветерок 🌬️** | Сдувает в сторону | Стрелять лучиками |
| **Тучка ⛈️** | Метает молнии | Прыгать выше |
| **Летучая мышь 🦇** | Пикирует сверху | Стрелять издалека |
| **Паучок 🕷️** | Плетёт паутину | Не попадаться |
| **Змейка 🐍** | Ползает быстро | Перепрыгивать |

**Механика превращения:**
- Попадание лучиком = урон врагу
- Когда здоровье врага = 0, он **превращается в друга**!
- Превращённый враг становится розовым и добрым!

## 🎯 Цель игры

1. **Собрать все облачка** в каждом уровне
2. **Найти всех друзей** (пчёлки, божьи коровки, и т.д.)
3. **Превратить врагов в друзей** лучиками света
4. **Добраться до выхода** (правая часть уровня)

---

## 🌈 Философия игры

> **"Дружба и свет побеждают тьму!"**

Эта игра — о **доброте**, **дружбе** и **взаимопомощи**.
- Вы не убиваете врагов, а **превращаете их в друзей** лучиками света
- Вы **собираете друзей** и становитесь сильнее вместе
- Вы **помогаете** маленьким существам

**Никакой жестокости!** Только любовь, радуга и sunshine! 🌞💕
