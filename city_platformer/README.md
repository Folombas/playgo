## 📖 Описание

**2087 год. Нео-Токио.**

Вы — **KAI**, элитный хакер-беглец, укравший данные у мегакорпорации **Zaibatsu Corp**.

Ваша задача:
- Сбежать из нижних уровней города
- Взломать контрольные точки
- Избегать корпоративных солдат и дронов
- Добраться до зоны эвакуации

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| **A / ←** | Бежать влево |
| **D / →** | Бежать вправо |
| **W / ↑ / Пробел** | Прыжок (двойной в воздухе!) |
| **Shift** | Рывок (dash) |
| **J / K** | Стрельба |
| **E** | Хакерство (взлом терминалов) |
| **L** | Бросить гранату |
| **I** | EMP-импульс |
| **ESC** | Пауза / меню |

## 🛠️ Технические детали

### Процедурная генерация уровней

1. **Террейн:** Пол с ямами (случайные разрывы)
2. **Платформы:** 5+level*2 случайных платформ
3. **Стены:** Для wall run
4. **Враги:** 3+level, типы зависят от уровня
5. **Терминалы и двери:** Препятствия
6. **Предметы:** 8+level*2 с весовой вероятностью
7. **Камеры и турели:** Системы безопасности

### Механики

**Паркур:**
- Двойной прыжок (второй слабее)
- Wall slide (замедление падения у стены)
- Wall jump (отталкивание от стены)
- Dash (рывок, тратит 25 энергии)

**Хакерство:**
- Мини-игра с движущейся полоской
- Нужно попасть в зелёную зону
- Прогресс взлома накапливается
- Успешный взлом открывает двери

**Стелс:**
- Камеры обнаруживают игрока
- Тревога влияет на спавн врагов
- Тени для скрытия (планируется)

**Бой:**
- Энерго-пистолет (бесконечные патроны)
- Гранаты (урон по области)
- EMP (оглушение врагов и турелей)
