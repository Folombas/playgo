# 🌃 Cyber City Runner

**Динамичный 2D платформер в стиле киберпанк на Go + Ebitengine**

**Go365 Challenge** — День 91 из 365 🐍

---

## 📖 Описание

2077 год. Вы — хакер-беглец, укравший секретные данные у мегакорпорации "NeoTech". 
Ваша задача — прорваться через неоновый город будущего, полный охранников, дронов 
и систем наблюдения, чтобы добраться до точки эвакуации.

---

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| **A / ←** | Бег влево |
| **D / →** | Бег вправо |
| **W / ↑ / Пробел** | Прыжок (двойной прыжок в воздухе) |
| **S / ↓** | Присесть / спуск |
| **Shift** | Рывок (dash) |
| **J** | Выстрел |
| **K** | Взлом / взаимодействие |
| **ESC** | Пауза / меню |

## 🎯 Цель игры

- Пройти все 10 уровней
- Собрать все дата-чипы
- Избежать обнаружения камерами
- Добраться до точки эвакуации

---

## 👾 Враги

| Тип | Описание | Тактика |
|-----|----------|---------|
| **Дрон ** | Летает, стреляет лазерами | Уничтожить издалека |
| **Робопёс 🤖** | Быстрый, патрулирует зону | Перепрыгнуть или уничтожить |
| **Турель 🔫** | Статичная, стреляет при приближении | Уничтожить или обойти |
| **Камера 📷** | Обнаруживает, поднимает тревогу | Избегать поля зрения |

1. **Трущобы** — Обучение, простые враги

3. **Нижний город** — Камеры наблюдения

8. **Военная база** — Много врагов

## 🎮 Особенности реализации

### Компонентная архитектура (ECS)
- **Transform** — позиция, размер, скорость
- **Physics** — гравитация, трение, коллизии
- **Health** — здоровье, неуязвимость
- **SpriteRenderer** — отрисовка спрайтов
- **Animator** — управление анимациями

### Процедурная генерация уровней
- Случайные платформы и препятствия
- Расстановка врагов и предметов
- Увеличение сложности с каждым уровнем

### Система рывка (dash)
- Расходует энергию
- Короткое ускорение в направлении движения
- Перезарядка

### Система обнаружения
- Камеры имеют поле зрения
- При обнаружении — тревога
- Больше врагов появляется
