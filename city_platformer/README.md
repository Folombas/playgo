# 🌈 Sunny Adventure: Приключения Зайчика

**Добрый 2D платформер в стиле сказочного приключения на Go + Ebitengine**

**Go365 Challenge** — День 91 из 365 🐍

---

## 📖 Описание

Милый зайчик 🐰 проснулся утром и обнаружил, что его друзья-облачка ☁️ 
разлетелись по всему королевству! Злой ветер разбросал их по разным землям.

**Ваша задача** — собрать всех друзей-облачков, победить злого ветра и вернуть 
радость в небесное королевство!

---

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| **A / ←** | Бежать влево |
| **D / →** | Бежать вправо |
| **W / ↑ / Пробел** | Прыжок (можно прыгать в воздухе!) |
| **S / ↓** | Присесть / спуститься вниз |
| **J** | Бросить морковку 🥕 |
| **K** | Обнять друга (лечение) |
| **ESC** | Пауза / меню |

## 🎯 Цель игры

1. **Собрать все облачка** в каждом уровне (спрятаны в сундуках)
2. **Найти всех друзей** (пчёлки, лягушки, улитки)
3. **Победить босса** в конце каждого мира
4. **Добраться до финального замка** и победить Короля Ветров!

## 🌈 Философия игры

> **"Дружба и свет побеждают тьму!"**

Эта игра — о **доброте**, **дружбе** и **взаимопомощи**. 
- Вы не убиваете врагов, а **превращаете их в друзей** лучиками света
- Вы **обнимаете** маленьких существ, а не сражаетесь с ними
- Вы **собираете друзей** и становитесь сильнее вместе

**Никакой жестокости!** Только любовь, радуга и sunshine! 🌞💕

## 🎨 Особенности реализации

### Компонентная архитектура (ECS)
- **Transform** — позиция, размер, скорость
- **Physics** — гравитация, трение, прыжки
- **Light** — солнечная энергия, излучение
- **Friendship** — счётчик друзей, уровень дружбы
- **SpriteRenderer** — отрисовка спрайтов
- **Animator** — анимации

### Система света
- Динамическое освещение
- Тени от платформ
- Светящиеся частицы

### Механика дружбы
- Обнимашки с существами
- Превращение врагов в друзей
- Бонусы за количество друзей

### Процедурная генерация
- Случайные платформы
- Облачка-сюрпризы
- Секретные области
