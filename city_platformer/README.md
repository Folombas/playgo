# 🏙️ City Platformer - Last Survivor

**2D платформер с использованием PlatformerComplete Pack**

---

## 🎮 Описание

**City Platformer** — это динамичный 2D платформер где ты играешь за последнего выжившего!

**Особенности:**
- 🎨 **PlatformerComplete спрайты** - полноценные анимированные текстуры
- 🔫 **Система стрельбы** - сражайся с врагами на расстоянии
- 🎯 **Комбо-система** - набирай очки за быстрые убийства
- 👾 **Разнообразные враги** - слаймы, мухи, улитки, рыбы
- 🏆 **Босс-файты** - эпичные сражения с боссами каждые 3 уровня
- ❤️ **Система жизней** - 5 жизней на прохождение
- 🌊 **Волны врагов** - прогрессирующая сложность
- ☁️ **Параллакс фон** - облака на заднем плане

---

## 🎨 Спрайты

Используются спрайты из **PlatformerComplete Base Pack**:

### Игрок (Player 1)
- 🚶 11 кадров анимации ходьбы
- 🦘 Прыжок
- 🦆 Приседание
- 💥 Получение урона

### Враги
- 🟣 **Слайм** - 2 кадра анимации
- 🟡 **Муха** - 2 кадра, летает
- 🟠 **Улитка** - 2 кадра, медленная
- 🔵 **Рыба** - 2 кадра, плавает

### Платформы
- 🌿 Grass - земля с травой
- 🟫 Dirt - земля
- 🪨 Stone - камень
- 🏰 Castle - замок
- 📦 Box - ящики

### Предметы
- 🪙 Монеты (золото, серебро, бронза)
- 💎 Гемы (красный, синий, зелёный, жёлтый)
- ⭐ Звезда
- 🍄 Грибы

### Декорации
- ☁️ Облака (3 типа)
- 🌿 Кусты
- 🌱 Растения
- 🪨 Камни
- 🌵 Кактусы

## 🏆 Боссы

Каждые 3 уровня после 3-й волны появляется **БОСС**:
- ❤️ 50 единиц здоровья
- 🔥 Стреляет залпами из 5 снарядов
- 💀 500 очков за убийство

---

## 🎮 Игровая механика

### Комбо-система
- Убивай врагов быстро для поддержания комбо
- Каждое комбо умножает очки
- Комбо сгорает через 3 секунды без убийств

### Очки
- 🪙 Золотая монета: 10 очков
- 💎 Гем: 50 очков
- 👾 Враг: 25 × (1 + комбо) очков
- 🏆 Босс: 500 очков
