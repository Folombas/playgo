# 🏡 Деревенский Платформер

**Классический 2D-платформер с деревенскими домиками, деревьями и холмами на Go + Ebitengine**

**Go365 Challenge** — День 93 из 365 🐍

---

## 📖 Описание

**Спокойная прогулка по живописной деревне!**

Вы — путник, который гуляет по красивой деревне. Вокруг:
- 🏡 Деревенские домики с двускатными крышами
- 🌲 Ёлки и деревья
- 🌳 Лужайки и холмы
- 💰 Монетки для сбора
- ⭐ Звёзды-бонусы

**Ваша задача** — собрать все звёзды и добраться до выхода!

---

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| **A / ←** | Идти влево |
| **D / →** | Идти вправо |
| **W / ↑ / Пробел** | Прыжок (можно дважды!) |
| **ESC** | Пауза / меню |

## 🌟 Игровая механика

### Классический 2D-платформер
- **Бег и прыжки** слева направо
- **Двойной прыжок** в воздухе
- **Сбор монеток** по пути
- **Избегание врагов** (слизни, змейки, пауки)

### Цель уровня
1. **Собрать все звёзды** (5-7 на уровень)
2. **Добраться до выхода** (правая часть уровня, x > 2000)
3. **Набрать максимум очков**

### Типы домиков:

## 🏗️ Структура уровней

### Генерация:
| Параметр | Формула |
|----------|---------|
| Ширина уровня | 2500 + level * 500 |
| Количество домиков | 2 + level |
| Количество деревьев | 8 + level * 2 |
| Количество холмов | 5 + level |
| Количество монеток | 15 + level * 3 |
| Количество звёзд | 5 + level |
| Количество врагов | 3 + level |

### Прогрессия:
- **Уровень 1-2:** Обучение, мало врагов
- **Уровень 3-4:** Больше домиков и деревьев
- **Уровень 5+:** Сложная навигация
