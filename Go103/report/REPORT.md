# Отчёт о разработке - Go103

## Дата: 13 апреля 2026

## Задача
Создать казуальную карманную игру "Три в ряд" (Match-3) на Go с Ebitengine.

## Выполненная работа

### Создано с нуля
- Полностью рабочая Match-3 игра
- 8 файлов кода (main, game, board, animation, ui, input, sounds, assets)
- Web-версия (index.html для WASM)
- Документация (README, CHANGELOG)

### Ключевые механики
1. **Игровое поле 8x8** - генерация без начальных комбинаций
2. **Система обмена** - валидация, анимация, откат при ошибке
3. **Обнаружение матчей** - горизонтальные + вертикальные комбинации 3+
4. **Каскадная система** - цепочки комбо при падении фишек
5. **Система очков** - 10 pts/фишка + бонусы (4: +50, 5+: +100)
6. **Таймер** - 60 секунд с обратным отсчётом
7. **Подсказки** - автоподсказка через 5 сек бездействия
8. **Game Over** - финальный счёт, кнопка "Play Again"

### Анимации (6 типов)
- Swap (150ms) - плавный обмен
- Shake (150ms) - дрожание при ошибке (3 цикла x 50ms, ±4px)
- Match (200ms) - fade-out + scale down
- Drop (250ms) - падение с quadratic easing
- Hint (2000ms) - пульсация зелёной рамки
- Score - всплывающие очки (заглушка)

### Звуки (4 типа)
Все звуки сгенерированы процедурно (синусоидальные волны):
- Swap: 440Hz, 100ms (Ля первой октавы)
- Match: 880Hz, 200ms (Ля второй октавы)
- Error: 220Hz, 150ms (Ля малой октавы)
- Game Over: 330Hz, 500ms (Ми первой октавы)

### Архитектура
Чистое разделение ответственности:
- `main.go` - точка входа, инициализация Ebitengine
- `game.go` - игровой цикл, состояние, логика
- `board.go` - логика поля (матчи, обмены, каскад)
- `animation.go` - система анимаций
- `ui.go` - отрисовка UI
- `input.go` - обработка ввода
- `sounds.go` - звуковая система
- `assets.go` - встраивание ресурсов
