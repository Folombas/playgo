# Go103 - Match-3 Game (13 апреля 2026)

## Задача на сегодня
Создать с нуля казуальную "карманную" игру "Три в ряд" на Go с Ebitengine.

## План реализации

### Архитектура
- `main.go` - точка входа, инициализация Ebitengine
- `game.go` - основной игровой цикл, состояние игры
- `board.go` - логика игрового поля (8x8), матчи, обмены, каскад
- `animation.go` - система анимаций (swap, match, drop, shake)
- `ui.go` - отрисовка UI (score, timer, buttons, game over screen)
- `input.go` - обработка мыши/тача
- `sounds.go` - загрузка и воспроизведение звуков
- `assets.go` - встраивание ресурсов через go:embed

### Ключевые механики
1. Поле 8x8, 6 типов фишек
2. Начальное поле без готовых комбинаций
3. Обмен соседних фишек с проверкой валидности
4. Удаление комбинаций 3+ с анимацией
5. Падение новых фишек сверху
6. Каскадные комбо
7. Таймер 60 секунд
8. Подсказки при 5 сек бездействия
9. Система очков (бонусы за 4 и 5 фишек)
10. Сохранение рекорда

### Ресурсы
Спрайты будут взяты из папки `D:\Projects\sprites\` (Food, Characters и т.д.)

### Платформы
- Windows (основная)
- Android (gomobile)
- Web (WASM)
