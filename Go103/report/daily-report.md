#### Игровые механики

1. **Управление**:
   - **WASD** — движение персонажа
   - **МЫШЬ** — прицеливание (линия прицела)
   - **ЛКМ** — автоматическая стрельба
   - **ESC/P** — пауза

2. **3 типа врагов**:
   - 🔴 **Обычные** (красные): стандартная скорость и HP
   - 🟡 **Быстрые** (желтые): высокая скорость, мало HP
   - 🟣 **Танки** (фиолетовые): медленные, много HP, появляются с волны 5

3. **Волновая система**:
   - Каждая волна: 5 + (волна × 3) врагов
   - Нарастающая сложность: больше HP, скорости
   - Экран "ВОЛНА ПРОЙДЕНА" между волнами
   - Спавн врагов с краёв экрана

4. **Система частиц**:
   - 💥 Взрывы при уничтожении врагов (20 частиц)
   - ✨ Вспышки при попадании (8 частиц)
   - 🔥 Trail-эффект пуль
   - ⚡ Эффекты при сборе power-up
   - 💫 Muzzle flash при стрельбе

5. **Screen shake**:
   - Тряска экрана при попаданиях
   - Интенсивность зависит от события
   - Плавное затухание

6. **Power-ups** (25% шанс выпадения):
   - ❤️ **Здоровье** (красный): +30 HP
   - ⚔️ **Урон** (оранжевый): +5 к урону
   - 💨 **Скорость** (голубой): +0.5 к скорости

7. **Комбо-система**:
   - Множитель очков за серии убийств
   - Комбо сбрасывается через 2 секунды
   - Формула: 100 × (1 + combo × 0.2)

8. **HUD**:
   - HP бар с цветовой индикацией (зеленый/желтый/красный)
   - Текущий счёт
   - Номер волны
   - Комбо-множитель

9. **Состояния игры**:
   - 🏠 Главное меню с декоративными элементами
   - 🎮 Игровой процесс
   - ⏸️ Пауза с кнопками "Продолжить" и "В меню"
   - 💀 Game Over с статистикой и "Новый рекорд"

### 🐛 Исправленные баги

#### Ошибки компиляции Ebitengine v2.9.9:
1. **vector.StrokeLine** требует float32, не float64 → добавлены явные приведения
2. **vector.DrawFilledRect** требует float32, не float64 → исправлены все вызовы
3. **vector.StrokeRect** требует float32 → конвертированы координаты кнопок
4. **Удалён unused field** PlayerImgs из Game struct
5. **Исправлена ошибка** с type assertion на ebiten.Image → заменено на ebiten.NewImage()

**Урок**: Ebitengine v2.9.x использует float32 для векторных функций, не float64!
