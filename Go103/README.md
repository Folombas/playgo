# Match-3 Game - Игра "Три в ряд"

Казуальная карманная игра на Go с использованием Ebitengine (v2.6+).

## 🎮 Особенности

- **Игровое поле 8x8** с 6 типами фишек (цвета)
- **Автоматическое обнаружение комбинаций** (горизонтальные и вертикальные)
- **Каскадная система** - комбо-цепочки при падении новых фишек
- **Анимации**: обмен, дрожание (ошибка), удаление, падение, подсказки
- **Звуковые эффекты** (программно сгенерированные, без внешних файлов)
- **Таймер 60 секунд** с обратным отсчётом
- **Система очков**: 10 pts за фишку + бонусы (4: +50, 5+: +100)
- **Авто-подсказки** через 5 секунд бездействия
- **Адаптивный интерфейс** под разные разрешения экрана
- **Кроссплатформенность**: Windows, Android, Web (WASM)

## 📦 Установка и запуск

### Windows (Desktop)

```bash
# Клонируйте или перейдите в папку проекта
cd Go103

# Установите зависимости
go mod tidy

# Запустите игру
go run .

# Или соберите EXE
go build -o match3.exe
.\match3.exe
```

### Web (WASM)

```bash
# Соберите WASM модуль
GOOS=js GOARCH=wasm go build -o game.wasm

# Скопируйте wasm_exec.js изGOROOT
cp "$(go env GOROOT)/misc/wasm/wasm_exec.js" .

# Запустите HTTP сервер
python -m http.server 8080

# Откройте http://localhost:8080 в браузере
```

### Android (через gomobile)

```bash
# Установите gomobile
go install golang.org/x/mobile/cmd/gomobile@latest
gomobile init

# Соберите APK
gomobile build -target=android -o match3.apk

# Установите на устройство
adb install match3.apk
```

## 🏆 Система очков

- **Базовые очки**: 10 очков за каждую фишку в комбинации
- **Бонус за 4 фишки**: +50 очков
- **Бонус за 5+ фишек**: +100 очков

**Примеры:**
- 3 фишки = 30 очков
- 4 фишки = 90 очков (40 + 50)
- 5 фишек = 150 очков (50 + 100)
- Каскад (2 комбинации подряд) = сумма обеих

## 🎨 Добавление своих спрайтов

Игра автоматически использует программную графику (цветные круги), но вы можете заменить их на спрайты:

1. Поместите PNG файлы в папку `sprites/`
2. Имена файлов: `tile_0.png` ... `tile_5.png`, `button.png`, `background.png`
3. Рекомендуемый размер: 64x64 пикселя
4. Перекомпилируйте: `go build`

Спрайты автоматически встраиваются в бинарник через `//go:embed sprites/*`.

## 🧪 Тестирование

### Проверка каскада
1. Создайте ситуацию где после удаления комбинации новые фишки образуют ещё одну
2. Наблюдайте каскадную анимацию и начисление комбо-очков

### Проверка подсказки
1. Не делайте ход в течение 5 секунд
2. Должна появиться пульсирующая зелёная подсветка на валидной паре фишек

### Проверка анимаций
- **Swap**: Кликните на фишку, затем на соседнюю (валидный обмен)
- **Shake**: Попробуйте обменять фишки которые не дают комбинацию
- **Match**: Наблюдайте fade-out + scale down при удалении
- **Drop**: Новые фишки падают сверху с easing

### Проверка Game Over
1. Подождите 60 секунд
2. Появится экран с финальным счётом и кнопкой "Play Again"
