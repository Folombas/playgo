# Match-3 — Карманная игра «Три в ряд»

## 🎮 Описание
Казуальная игра «Три в ряд» на **Go** с движком **Ebitengine**.
Поле 8×8, 6 цветов фишек, таймер 60 секунд, система очков с бонусами за каскады.

## 🚀 Запуск

### Desktop (Linux/Windows/macOS)
```bash
cd Go103/match3
go run .
```

### Сборка бинарника
```bash
go build -o match3
./match3
```

## 🎯 Управление
- **ЛКМ** — выбор и обмен фишек
- **R** — новая игра
- **P** — пауза

## 🏆 Очки
- Комбинация из 3 фишек: **10 очков** за фишку
- Комбинация из 4 фишек: **+50 бонус**
- Комбинация из 5+ фишек: **+100 бонус**
- Каскадные комбо: **+5 за каждый уровень**

## 📦 Зависимости
- `github.com/hajimehoshi/ebiten/v2` — игровой движок
- `github.com/hajimehoshi/ebiten/v2/vector` — векторная графика
- `github.com/hajimehoshi/ebiten/v2/audio` — звуки
- `github.com/hajimehoshi/ebiten/v2/ebitenutil` — утилиты

## 🏗️ Архитектура
```
match3/
├── main.go        # Точка входа, ebiten.RunGame
├── game.go        # Состояние игры, Update, каскады
├── board.go       # Логика поля, поиск совпадений
├── animation.go   # Система анимаций
├── ui.go          # Отрисовка UI
├── input.go       # Обработка мыши/тача
├── sounds.go      # Программная генерация звуков
└── assets.go      # Процедурная генерация спрайтов
```

## 🎨 Спрайты
Спрайты генерируются процедурно (цветные круги с обводкой и бликом).
Для замены на PNG — положите файлы в `sprites/tile_0.png` ... `tile_5.png`.
