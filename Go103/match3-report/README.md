## 📝 Архитектура

### Структуры данных
```go
type Game struct {
    State        GameState     // Текущее состояние
    Board        *Board        // Игровое поле
    Score        int           // Текущий счёт
    Combo        int           // Текущее комбо
    MaxCombo     int           // Максимальное комбо
    Timer        float64       // Оставшееся время
    SelectedTile *Tile         // Выбранная фишка
    HintActive   bool          // Активна ли подсказка
    GemImages    []*ebiten.Image // Загруженные спрайты
}

type Board struct {
    Tiles [][]*Tile  // Двумерный массив фишек
}

type Tile struct {
    GemType   int      // Тип кристалла (0-5)
    Row, Col  int      // Позиция в сетке
    X, Y      float64  // Текущие координаты
    TargetX   float64  // Целевые координаты
    TargetY   float64
    Selected  bool     // Выбрана ли
    Removing  bool     // Удаляется ли
    Scale     float64  // Масштаб (для анимации)
    Alpha     float64  // Прозрачность
    ShakeTime float64  // Время дрожания
}
```

### Паттерны проектирования
- **Game Loop:** Классический игровой цикл Update/Draw
- **Component:** Tile как независимый компонент
- **State Machine:** GameState для управления экранами
- **Interpolation:** Плавные анимации через Lerp
