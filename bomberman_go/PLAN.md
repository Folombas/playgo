# Bomberman Go - План разработки

## Цель
Создать полноценную копию классической Bomberman на Go + Ebitengine для практики продвинутого Go.

## Архитектура проекта

### Структура
```
bomberman_go/
├── cmd/
│   └── main.go           # Точка входа
├── internal/
│   ├── game/             # Игровые сцены
│   │   ├── scene.go      # Базовая сцена
│   │   ├── menu.go       # Главное меню
│   │   ├── gameplay.go   # Основной геймплей
│   │   └── gameover.go   # Экран смерти
│   ├── engine/           # Игровой движок
│   │   ├── update.go     # Логика обновлений
│   │   ├── render.go     # Рендеринг
│   │   └── input.go      # Обработка ввода
│   ├── entity/           # Игровые сущности
│   │   ├── player.go     # Игрок
│   │   ├── enemy.go      # Враги
│   │   ├── bomb.go       # Бомбы
│   │   ├── explosion.go  # Взрывы
│   │   ├── wall.go       # Стены
│   │   ├── powerup.go    # Бонусы
│   │   └── grid.go       # Игровое поле
│   └── config/           # Конфигурация
│       ├── constants.go  # Константы
│       └── assets.go     # Загрузка ассетов

```

## Игровые механики

### Основное поле
- Сетка 13x11 (классический Bomberman)
- Размер тайла: 64x64 пикселя
- Неразрушаемые стены (камень) - статичная сетка
- Разрушаемые стены (кирпич) - случайно размещены

### Игрок
- Движение по сетке (WASD/стрелки)
- Установка бомб (Пробел)
- 3 жизни
- Анимация ходьбы (2 кадра)

### Бомбы
- Таймер: 2 секунды
- Радиус взрыва: 3 клетки (увеличивается бонусами)
- Цепные реакции
- Анимация пульсации

### Взрывы
- Крестообразная форма
- Распространение по 4 направлениям
- Уничтожение кирпичных стен
- Урон игроку и врагам
- Анимация (3 кадра)

### Враги (3 типа)
1. **Balloon** - случайное движение, медленный
2. **Onil** - движение к игроку, средний
3. **Minvo** - преследование игрока, быстрый

### Бонусы
- 🔥 Огонь (увеличение радиуса)
- 💣 Бомба (+1 бомба)
- ⚡ Скорость
- ❤️ Жизнь
- 🛡️ Щит

### Уровни
- 5 уровней с нарастающей сложностью
- Больше врагов
- Больше препятствий
- Дверь для перехода на следующий уровень

## Технические детали

### Ebitengine
- Игра в полноэкранном режиме 832x704 (13x11 тайлов)
- TPS: 60
- Использование `ebiten.DrawImage` для спрайтов
- Tilemap-based рендеринг

### Управление состоянием
- Машина состояй для сцен
- Компонентная система для сущностей
- Event-based архитектура

### Коллизии
- AABB для простых объектов
- Grid-based для тайлов
- Raycasting для взрывов

### Оптимизация
- Object pooling для бомб и взрывов
- Sprite batch для рендеринга
- Кэширование спрайтов
