# Jungle Crystal Adventure 🌿💎

**2D-платформер в стиле джунглей с коллекционированием кристаллов**

---

## 🎮 Описание

Jungle Crystal Adventure — это новый 2D-платформер, созданный в рамках Go365 челленджа (День 87). 
Игра использует движок Ebitengine и написана на языке Go.

**Сеттинг:** Экзотические джунгли с древними кристаллами
**Жанр:** 2D Platformer / Adventure
**Цель:** Собрать все кристаллы и добраться до флага

---

## 🚀 Запуск

```bash
cd jungle_crystal
go run main.go
```

Или запустить скомпилированный бинарник:

```bash
./jungle_crystal.exe
```

| Клавиша | Действие |
|---------|----------|
| ← / A | Движение влево |

## ✨ Особенности

### Новая механика — Кристаллы 💎
- **5 типов кристаллов** разных цветов (красные, зелёные, синие, жёлтые, фиолетовые)
- Кристаллы появляются случайно по всему уровню
- Анимация парения в воздухе
- Система частиц при сборе
- Достижение "Коллекционер кристаллов" (50 кристаллов)

### Враги 👾
- 12+ типов врагов с уникальным поведением
- Наземные: Goomba, Koopa, Mouse, Snail
- Летающие: Fly, Ladybug
- Прыгающие: Frog
- Специальные: Piranha, Saw, Worm, Fish

### Игровые объекты 🎮
- **Монеты** — классическая валюта
- **Ключи** — открывают сундуки
- **Сундуки** — сокровища и бонусы
- **Пружины** — высокие прыжки
- **Телепорты** — быстрое перемещение
- **Шипы** — опасности
- **Флаг** — финиш уровня

### Power-ups 🍄
- 🍄 Гриб — увеличение
- 🌸 Цветок — огненная сила
- ⭐ Звезда — неуязвимость (10 сек)
- 🍄 1UP — дополнительная жизнь
- 💎 Кристалл — бонусные очки

## 🎯 Игровой процесс

1. **Старт:** Запустите игру, нажмите ENTER
2. **Движение:** Используйте стрелки или WASD
3. **Сбор:** Собирайте кристаллы и монеты
4. **Бой:** Прыгайте на врагов сверху
5. **Финиш:** Доберитесь до флага

### Комбо-система
- Прыгайте на врагах подряд
- Максимальное комбо: x10
- Множитель очков: 1x + 0.5x за каждый уровень
- Таймер комбо: 2 секунды
