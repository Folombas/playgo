## 🎮 НОВОЕ: go_mario v8.0.0

### Что добавлено

#### 1. POWER-UPS 🍄
**4 типа бонусов:**

| Тип | Спрайт | Эффект |
|-----|--------|--------|
| 🍄 **Mushroom** | mushroomRed | +20 Max HP + полное лечение |
| ⭐ **Star** | star | +500 очков |
| 🌸 **Flower** | flower1 | +10 монет |
| 🍞 **1UP** | mushroomBrown | +1 жизнь |

**Механики:**
- **Спавн:** 2% шанс на tile
- **Магнит:** Притяжение с расстояния 100px
- **Анимация:** Покачивание (bobbing)
- **Частицы:** Разные цвета для каждого типа

#### 2. ДОСТИЖЕНИЯ 🏆
**5 ачивок:**

```go
"first_blood"     — Победите первого врага
"coin_master"     — Соберите 50 монет
"boss_slayer"     — Победите босса
"survivor"        — Достигните 3 мира
"world_conqueror" — Пройдите все миры
```

**Отображение:**
- В правом нижнем углу HUD
- Золотой цвет текста
- Показываются только разблокированные

#### 3. УЛУЧШЕНИЯ
- **Инициализация** достижений при старте
- **Частицы** при сборе power-ups
- **Магнитный эффект** для предметов
- **Анимация** покачивания (sin wave)
