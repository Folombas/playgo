### Технические изменения
- **Векторная графика** — всё рисуется кодом через vector
- **ECS-подобная архитектура** — разделение сущностей
- **Процедурная анимация** — математика для движений
- **Система частиц** — эффекты для красоты

### Управление
- **WASD / Стрелки** — перемещение
- **E** — посадить растение (случайное)
- **B** — режим строительства
- **I** — инвентарь
- **1-5** — выбор постройки
- **ЛКМ** — разместить постройку
- **ESC** — пауза
- **SPACE** — начать игру

### Сборка
```bash
cd dungeon_survivor
go build -o dungeon_survivor.exe .
```
