# 🏠 Village Platformer

**Классический 2D-платформер на Go + Ebitengine**

---

## 📖 Описание

**Village Platformer** — это добрый 2D-платформер в классическом стиле:

- 🏃 **Бег и прыжки** по уровню слева направо
- 🏠 **Уютные домики** с двускатными крышами и трубами
- 🏭 **Дым из труб** создаёт атмосферу деревни
- 🌲 **Деревья и ёлки** (дуб, сосна, берёза)
- ⛰️ **Холмы и лужайки** для красоты
- 💰 **Сбор монеток** на платформах
- 🚩 **Флаг победы** в конце уровня
- ☁️ **Облака и солнце** на небе

**Вдохновение:** Super Mario, Stardew Valley, классические платформеры

---

```bash
cd dungeon_survivor

```

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| **A / D** или **← / →** | Бег влево/вправо |
| **W / ↑ / SPACE** | Прыжок |
| **ESC** | Пауза / Выход |
| **SPACE** (в меню) | Начать игру |

## 🎯 Геймплей

### Цель игры
Достигнуть **флага** в конце уровня, собирая **монетки** и избегая падения в пропасть!

### Особенности
- **Физика** — гравитация, инерция, прыжки
- **Коллизии** — платформы, земля
- **Камера** — слежение за игроком
- **Процедурная генерация** — каждый уровень уникален
- **Параллакс** — холмы и деревья движутся с разной скоростью

### Препятствия
- 🕳️ **Пропасти** — падение = потеря жизни
- 📦 **Платформы** — разной высоты и ширины
- 🏠 **Домики** — украшают уровень
