# 🎮 Dungeon Survivor

**Roguelike Survivor игра на Go + Ebitengine**

---

## 📖 Описание

**Dungeon Survivor** — это roguelike survivor в стиле Vampire Survivors:

- 🎯 **Автоматическая атака** — герой стреляет сам
- 🏃 **Только движение** — управляй стрелками/WASD
- 👾 **Орды врагов** — выживай в волнах монстров
- ⬆️ **Улучшения** — выбирай 3 случайных из 10 (в разработке)
- 💀 **Permadeath** — смерть = начало заново
- 📊 **Мета-прогрессия** — прокачка между забегами (в разработке)

---

## 🚀 Быстрый старт

```bash
cd dungeon_survivor
go mod tidy
go run main.go
```

---

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| **WASD** / **Стрелки** | Перемещение героя |
| **SPACE** | Начать игру / Рестарт |
| **ESC** | Пауза / Выход |

## 🏗️ Архитектура проекта

```
dungeon_survivor/
├── internal/         # Приватный код приложения
│   ├── game/         # Игровая логика
│   ├── entity/       # Сущности (игрок, враги, снаряды)
│   ├── system/       # Системы (бой, спавн, коллизии)
│   ├── render/       # Рендеринг и UI
│   └── audio/        # Звуковая система
├── assets/           # Ресурсы игры
├── main.go           # Точка входа
└── go.mod            # Зависимости
```
