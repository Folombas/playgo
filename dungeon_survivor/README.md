# 🌸 Kingdom Garden

**Мирная игра-песочница на Go + Ebitengine**

---

## 📖 Описание

**Kingdom Garden** — это добрая, уютная игра-песочница где ты создаёшь красивое королевство:

- 🌸 **Сажай растения** — деревья, цветы, кусты
- 🏰 **Строй здания** — замки, домики, заборы
- 🦋 **Наблюдай за животными** — кролики, птички, бабочки
- ☁️ **Наслаждайся видом** — облака, солнце, смена времени суток
- 🌈 **Никаких врагов** — только созидание и красота!

**Вдохновение:** Stardew Valley, Animal Crossing, Dorfromantik

---

## 🚀 Быстрый старт

```bash
cd dungeon_survivor
go mod tidy
go run main.go
```

---

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| **WASD** / **Стрелки** | Перемещение героя |
| **E** | Посадить растение |
| **B** | Режим строительства |
| **I** | Инвентарь |
| **1-5** | Выбор постройки (в режиме строительства) |
| **ЛКМ** | Разместить постройку |
| **ESC** | Пауза / Выход |
| **SPACE** | Начать игру (в меню) |

## 🎯 Философия игры

**Мир. Созидание. Красота.**

В мире нет врагов. Нет насилия. Нет стресса. Только ты и твой прекрасный сад.

- 🌱 **Созерцание** — наблюдай за ростом растений
- 🏗️ **Творчество** — строй и украшай королевство
- 🦋 **Гармония** — животные живут в твоём саду
- ⏰ **Релакс** — играй в своём темпе


## 🎓 Go-концепции

Этот проект изучает:

1. **ECS (Entity-Component-System)** — архитектура игры
2. **Векторная графика** — рисование кодом
3. **Система частиц** — визуальные эффекты
4. **Камера и скроллинг** — работа с большим миром
5. **Процедурная генерация** — создание ландшафта
6. **ИИ животных** — простое поведение NPC
7. **Состояния игры** — меню, игра, пауза, строительство
