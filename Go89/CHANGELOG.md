## 🎮 НОВОЕ: go_mario v9.0.0

### Что добавлено

#### 1. КОМБО-СИСТЕМА 🔥
**Механика:**
- Серии действий (сбор монет, удары врагов)
- Таймер комбо: 2 секунды (120 кадров)
- Максимальное комбо: x50
- Бонусные очки: `points * (combo / 5)`

**Отображение:**
```
🔥 COMBO x5!   (оранжевый, x2-x9)
🔥 COMBO x15!  (красный, x10-x19)
🔥 COMBO x25!  (фиолетовый, x20+)
```

**Достижение:**
- **Combo Master** — набрать комбо x20

#### 2. SCREEN SHAKE 📳
**Тряска экрана при событиях:**

| Событие | Сила |
|---------|------|
| Прыжок | 0 |
| Сбор монеты | 0 |
| Получение урона | 5 |
| Сбор power-up | 3 |
| Удар босса | 10 |
| Победа | 15 |

**Затухание:** `shake *= 0.9` каждый кадр

#### 3. ЗВУКОВЫЕ ЭФФЕКТЫ 🔊
**Визуальная обратная связь:**

```go
SoundJump   — lastJump таймер
SoundCoin   — lastCoin таймер
SoundHit    — shake 5
SoundPowerup — shake 3
SoundBoss   — shake 10
SoundWin    — shake 15
```

#### 4. УЛУЧШЕНИЯ
- **Audio struct** — управление звуком
- **playSound()** — воспроизведение эффектов
- **updateCombo()** — обновление таймера
- **addCombo()** — добавление к комбо
- **updateScreenShake()** — затухание тряски

## 🎮 Геймплей

### Комбо-механика
1. **Собирай монеты** — +1 к комбо
2. **Побеждай врагов** — +1 к комбо
3. **Держи серию** — не давай таймеру истечь
4. **Получай бонусы** — очки умножаются!

### Screen Shake
- **Тряска** при получении урона
- **Тряска** при победе над боссом
- **Плавное затухание** каждый кадр
