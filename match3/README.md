# Match-3: Три в ряд 🎮

Кросс-платформенная игра "Три в ряд", созданная на Go + Ebitengine в рамках Go365 Challenge (День 100).

## 🎯 Особенности

- **Классическая механика Match-3**: Обменивайте соседние камни, чтобы собрать 3+ в ряд
- **Комбо-система**: Последовательные матчи дают множитель очков
- **Визуальные эффекты**: Система частиц для взрывов и анимаций
- **Кросс-платформенность**: Windows, Web (WASM), Mobile, Telegram Apps

## 🚀 Установка и запуск

### Windows Desktop

```bash
# Перейти в директорию проекта
cd match3

# Запустить игру
go run ./cmd
```

### Web (WASM)

```powershell
# Windows PowerShell
.\build-web.ps1

# Запустить локальный сервер
cd web
python -m http.server 8080

# Открыть http://localhost:8080
```

### Mobile (Android/iOS)

```bash
# Установить gomobile
go install golang.org/x/mobile/cmd/gomobile@latest
gomobile init

# Собрать APK для Android
gomobile build -o match3.apk ./cmd

# Или для iOS (требуется macOS)
gomobile build -target=ios ./cmd
```

## 🎮 Управление

### Мышь
- **ЛКМ** - Выбрать камень
- **ЛКМ по другому камню** - Поменять местами (если соседние)

### Клавиатура
- **Shift + Стрелки** - Обмен с соседним камнем
- **ESC** - Выйти в меню
- **ENTER** - Начать игру / Рестарт

## 🎯 Игровые механики

1. **Выбор и обмен**: Кликните на камень, затем на соседний для обмена
2. **Матчи**: Соберите 3+ одинаковых камня в ряд
3. **Комбо**: Последовательные матчи без паузы дают множитель очков
4. **Гравитация**: Камни падают вниз после удаления матчей
5. **Game Over**: Игра заканчивается, когда нет доступных ходов

## 📊 Система очков

- Базовый матч (3 камня): 30 очков
- Базовый матч (4 камня): 40 очков
- Базовый матч (5+ камней): 50+ очков
- Комбо множитель: x2, x3, x4... за последовательные матчи

## 🛠 Технологии

- **Язык**: Go 1.25+
- **Движок**: Ebitengine v2.9.9
- **Web**: WebAssembly (WASM)
- **Mobile**: gomobile (Android/iOS)
