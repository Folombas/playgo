# Match-3: Три в ряд 🎮

Кросс-платформенная игра "Три в ряд", созданная на Go + Ebitengine в рамках Go365 Challenge (День 100).

## 🎯 Особенности

- **Классическая механика Match-3**: Обменивайте соседние камни, чтобы собрать 3+ в ряд
- **Комбо-система**: Последовательные матчи дают множитель очков
- **Визуальные эффекты**: Система частиц для взрывов и анимаций
- **Звуковые эффекты**: Программно генерируемые WAV звуки
- **Система уровней**: 10+ уровней с прогрессией сложности
- **Сохранение прогресса**: Автоматическое сохранение в JSON файл
- **Кросс-платформенность**: Windows, Web (WASM), Mobile, Telegram Apps

## 🚀 Установка и запуск

### Windows Desktop

```bash
# Перейти в директорию проекта
cd match3

# Запустить игру
go run ./cmd
```

### Web (WASM)

```powershell
# Windows PowerShell
.\build-web.ps1

# Запустить локальный сервер
cd web
python -m http.server 8080

# Открыть http://localhost:8080
```

### Mobile (Android/iOS)

```bash
# Установить gomobile
go install golang.org/x/mobile/cmd/gomobile@latest
gomobile init

# Собрать APK для Android
gomobile build -o match3.apk ./cmd

# Или для iOS (требуется macOS)
gomobile build -target=ios ./cmd
```

## 🎮 Управление

### Мышь
- **ЛКМ** - Выбрать камень
- **ЛКМ по другому камню** - Поменять местами (если соседние)

### Клавиатура
- **Shift + Стрелки** - Обмен с соседним камнем
- **ESC** - Пауза / Выйти в меню
- **P** - Пауза
- **ENTER** - Начать игру / Рестарт / Следующий уровень

## 🎯 Игровые механики

1. **Выбор и обмен**: Кликните на камень, затем на соседний для обмена
2. **Матчи**: Соберите 3+ одинаковых камня в ряд
3. **Комбо**: Последовательные матчи без паузы дают множитель очков
4. **Гравитация**: Камни падают вниз после удаления матчей
5. **Уровни**: 10+ уровней с возрастающей сложностью
6. **Звёзды**: Получайте 1-3 звезды за каждый уровень
7. **Game Over**: Игра заканчивается, когда нет доступных ходов

## 📊 Система очков

- Базовый матч (3 камня): 30 очков
- Базовый матч (4 камня): 40 очков
- Базовый матч (5+ камней): 50+ очков
- Комбо множитель: x2, x3, x4... за последовательные матчи
- Бонус за уровень: зависит от целевого очка

## 🎨 Спрайты и Звуки

### Спрайты
- 6 типов камней из пиксельного food pack (32x32)
- Красное яблоко, зелёная груша, жёлтый лимон, и т.д.
- Фоновое изображение из игрового набора
- Автоматическое копирование через `copy-sprites.ps1`

### Звуки
- Процедурно генерируемые WAV файлы
- 5 типов звуков: Match, Swap, Invalid, Combo, Game Over
- 3 варианта каждого звука для разнообразия
- Настройка громкости и mute

## 💾 Сохранение

Прогресс автоматически сохраняется в:
- **Windows**: `C:\Users\<username>\.match3_game\save.json`
- **Linux/Mac**: `~/.match3_game/save.json`

### Сохраняемые данные:
- Текущий уровень и общий счёт
- Рекорды для каждого уровня (очки, ходы, время, звёзды)
- Общая статистика (игры, победы, ходы, комбо)
- Настройки звука
