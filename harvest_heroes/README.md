# 🌾 Harvest Heroes 🗡️

**Farm & Dungeon RPG** — уникальная комбинация симулятора фермы и roguelike dungeon crawler'а!

## 🎮 Описание

Выращивайте культуры на своей ферме днём и исследуйте опасные подземелья ночью! Зарабатывайте золото, улучшайте инструменты, заводите друзей среди NPC и станьте легендой долины!

## 🚀 Запуск

```bash
cd harvest_heroes
go run main.go
```

Или запустить скомпилированный бинарник:

```bash
./harvest_heroes
```

## 🎯 Управление

| Действие | Управление |
|----------|------------|
| **Движение** | Стрелки / WASD |
| **Взаимодействие** | ЛКМ |
| **Атака** | Пробел / ЛКМ (в подземелье) |
| **Выбор инструмента** | Клик по иконке |
| **Меню** | ЛКМ по кнопкам |

## 🏗️ Игровая механика

### 🌾 Фермерство
- **Вспахивайте землю** мотыгой
- **Сажайте семена** различных культур
- **Поливайте растения** лейкой
- **Собирайте урожай** когда готово
- **Продавайте** в городе

### ⚔️ Подземелья
- **Процедурная генерация** этажей
- **Сражайтесь с монстрами** (слизни, летучие мыши, скелеты, призраки, демоны)
- **Открывайте сундуки** с сокровищами
- **Достигайте глубины** для лучших наград
- **Возвращайтесь живым** до ночи

### 🏘️ Город
- **Покупайте семена** у торговца
- **Общайтесь с NPC** (система диалогов)
- **Заводите друзей** (система отношений)
- **Тратьте золото** с умом

## 📊 Система времени

- **24-часовой цикл** (8 минут реального времени)
- **Энергия** тратится на действия
- **Восстановление** только ночью
- **Сон** в 00:00
- **Погода** меняется случайно

### Сезоны (каждые 30 дней)
| Сезон | Особенности |
|-------|-------------|
| 🌸 **Весна** | Базовый рост |
| ☀️ **Лето** | +20% рост |
| 🍂 **Осень** | +10% цена продажи |
| ❄️ **Зима** | -50% рост, снег |

## 🎯 Советы по игре

1. **Начните с пшеницы** — быстро растёт
2. **Всегда поливайте** — без воды не растёт
3. **Следите за энергией** — не тратьте всё
4. **Исследуйте подземелья** — там сокровища
5. **Возвращайтесь до ночи** — иначе потеряете энергию
6. **Копите на улучшения** — они окупятся
7. **Общайтесь с NPC** — откроете рецепты
