# Go365 - Day 97 | 6 апреля 2026 (понедельник)

## Новая игра: PUZZLE RAID 🎮

### Концепт
Аркадный паззл с элементами экшена:
- **Поле 8x8** заполнено цветными тайлами (4 цвета: blue, green, red, yellow)
- **Игрок** бегает по полю (WASD/стрелки)
- **Удар (SPACE)** — разбивает тайлы вокруг игрока
- **Match-3** — разбил 3+ тайла одного цвета = COMBO бонус
- **Враги** — 3 типа: slow, fast, smart (преследуют игрока)
- **Монеты** — выпадают из комбо, собираешь = +50 очков
- **Таймер** — нужно набрать X очков за Y секунд
- **Уровни** — каждый уровень сложнее: больше врагов, меньше времени

### Механики
| Элемент | Описание |
|---------|----------|
| WASD/Arrows | Движение по полю |
| SPACE | Удар по тайлам (радиус 1) |
| ESC/P | Пауза |
| Combo | 3+ тайла одного цвета = множитель очков |
| Враги | Отнимают жизни (3 жизни) |
| Монеты | +50 очков при сборе |
| Уровни | Прогрессия сложности |

### Спрайты
- **Тайлы**: 4 цвета × 72 спрайта = 288 файлов
- **Монеты**: 40 спрайтов анимации
- **Меню**: звёзды, кнопки (play, back)

### Архитектура

## Звуковая система 🎵

### 10 процедурных звуков (без внешних файлов!)

| Звук | Когда | Техника |
|------|-------|---------|
| **sndStrike** | Удар по тайлам | Impact sweep + high spark |
| **sndCoin** | Сбор монеты | High ping 1200Hz + harmonic 2400Hz |
| **sndCombo** | 3+ combo | Восходящее арпеджио C-E-G-C |
| **sndHit** | Урон игроку | Нисходящий sweep 400→80Hz + noise |
| **sndDeath** | Game Over | Мрачное арпеджио A-F#-D#-A + drone 110Hz |
| **sndWin** | Победа | Восходящее арпеджио + аккорд C-E-G |
| **sndMenu** | Клик в меню | Короткий beep 880Hz |
| **sndPause** | Пауза | Beep 440Hz |
| **sndStep** | Движение | Тихий click 300Hz |
| **sndTick** | Таймер <10с | Square wave 600Hz (ретро-тик) |

### Генераторы звуков
- `makeBeep()` — синус с затуханием
- `makeNoise()` — белый шум с экспоненциальным затуханием
- `makeSweep()` — sweep между частотами
- `makeArp()` — арпеджио по массиву нот
- `makeSquare()` — меандр (square wave) для ретро
- `makeChord()` — аккорд из нескольких нот
- `makeImpact()` — мощный удар (sweep + noise)
- `makeSpark()` — высокий звон/искра
