## 📊 Генерация уровней

### Параметры:

| Параметр | Формула |
|----------|---------|
| Ширина уровня | 2000 + level * 300 |
| Количество платформ | 5 + level * 2 |
| Количество врагов | 3 + level |
| Количество предметов | 8 + level * 2 |
| Количество данных | 3 (цель уровня) |

### Типы платформ:

1. **Земля** — grass + dirt
2. **Камень** — stone
3. **Кирпич** — brickWall
4. **Замок** — castle (финал)

| Клавиша | Действие |
|---------|----------|
| **A / ←** | Бежать влево |
| **D / →** | Бежать вправо |

## 🔧 Технические детали

### Реализованные системы:

1. **Физика:**
   - Гравитация: 1000 px/s²
   - Трение: 0.85
   - Скорость: 250 px/s
   - Прыжок: 500 px/s

2. **Коллизии:**
   - AABB (Axis-Aligned Bounding Box)
   - Проверка с платформами
   - Проверка с предметами
   - Проверка с врагами

3. **Анимации:**
   - Idle (стояние)
   - Walk (11 кадров, 8 FPS)
   - Jump (кадр прыжка)
   - Hurt (кадр получения урона)

4. **Камера:**
   - Следование за игроком
   - Плавное движение (lerp 0.1)
   - Ограничение по границам уровня

5. **Частицы:**
   - При прыжке
   - При сборе предметов
   - При выстреле
   - При получении урона
