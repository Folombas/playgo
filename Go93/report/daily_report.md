## 🎨 Рендеринг

### Без векторов!
```go
// БЫЛО (векторы):
vector.DrawFilledRect(...) // ❌

// СТАЛО (спрайты):
screen.DrawImage(sprite, opts) // ✅
```

### Масштабирование спрайтов:
```go
opts.GeoM.Scale(
    transform.Width / float64(sprite.Bounds().Dx()),
    transform.Height / float64(sprite.Bounds().Dy())
)
```

### Пиксельная отрисовка:
- **Без сглаживания** - чёткие пиксели
- **Целочисленное масштабирование** - кратное 1x, 2x, 3x
- **Пиксель-перфект** - каждый пиксель виден

## 🎮 Геймплей

### Управление:
- **A/D** - ходить влево/вправо
- **W/Пробел** - прыжок (двойной!)
- **ESC** - пауза

### Механики:
- **Бег и прыжки** - классика
- **Сбор монеток** - +10 очков
- **Сбор звёзд** - +50 очков, цель уровня
- **Избегание врагов** - слизни, змеи, пауки

### Цель:
1. Собрать все звёзды (5+level)
2. Добраться до выхода (x > 2000)
3. Набрать максимум очков
