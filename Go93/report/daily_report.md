## 🌍 Бесконечный мир

### Архитектура:

**Chunk (Чанк):**
- Ширина: 400 пикселей
- Содержит: платформы, домики, деревья, врагов, предметы
- Генерируется процедурно при приближении игрока
- Удаляется когда игрок уходит далеко

**World (Мир):**
- Map[int]*Chunk - активные чанки
- MaxChunks: 5 - максимум одновременно активных чанков
- Seed - случайное зерно для воспроизводимости

### Генерация чанка:

```go
generateChunk(chunk):
  1. Земля (с 20% шансом ямы)
  2. Холмы и платформы (2-5 шт)
  3. Домики (40% шанс, если нет ямы)
  4. Деревья (1-3 шт)
  5. Враги (60% шанс)
  6. Монетки (3-7 шт)
  7. Звёзды (30% шанс)
```

## 📊 Оптимизация

### Управление памятью:

**ActiveChunks:**
- Максимум: 5 чанков
- Удаляется самый левый (старый) чанк
- Добавляется новый правый чанк

**Алгоритм:**
```go
1. Игрок движется вправо
2. Достигает границы чанка N+1
3. Создаётся чанк N+1
4. Если активных > 5:
   - Удаляется чанк N-2
5. Продолжаем движение
```

### Производительность:

| Метрика | Значение |
|---------|----------|
| Чанков в памяти | ≤ 5 |
| Размер чанка | 400px |
| Активная зона | 2000px |
| FPS | 60 |
