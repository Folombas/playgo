## 🏡 Деревенские домики

### Конструкция домика:

**Размер:** 96x96 пикселей

**Части (9 спрайтов):**
```
┌─────────┐
│ 🏠 🏠 🏠 │  ← Крыша (topLeft, topMid, topRight)
│ 🏠   🏠 │  ← Стены (midLeft, midRight)
│ 🏠 🏠 🏠 │  ← Основание (bottomLeft, bottomMid, bottomRight)
└─────────┘
     ↑
   Труба с дымом!
```

### Типы домиков:
| Тип | Цвет стен | Цвет крыши |
|-----|-----------|------------|
| **Beige** | Светло-коричневый | Тёмно-коричневый |
| **Dark** | Тёмно-коричневый | Чёрный |
| **Gray** | Серый | Тёмно-серый |

### Анимация дыма:
- **Частицы** создаются каждые 0.5 сек
- **Поднимаются вверх** со скоростью 20 px/s
- **Колеблются** из стороны в сторону
- **Расширяются** со временем
- **Исчезают** через 2 секунды

## 🎮 Геймплей

### Управление:
- **A/D** - ходить влево/вправо
- **W/Пробел** - прыжок (двойной!)
- **ESC** - пауза

### Механики:
- **Бег и прыжки** - классический платформер
- **Двойной прыжок** - можно прыгнуть второй раз в воздухе
- **Сбор монеток** - +10 очков за каждую
- **Сбор звёзд** - +50 очков, цель уровня
- **Избегание врагов** - слизни, змейки, пауки

### Цель уровня:
1. Собрать все звёзды (5-7 на уровень)
2. Добраться до выхода (x > 2000)
3. Набрать максимум очков
