### 🌍 Новая система мира

#### Chunk (Чанк):
**Характеристики:**
- Ширина: 400 пикселей
- Генерируется процедурно
- Удаляется когда игрок уходит

**Содержимое чанка:**
```go
type Chunk struct {
  X            int
  Platforms    []*Platform
  Houses       []*House
  Trees        []*Tree
  Enemies      []*Enemy
  Items        []*Item
  Collectibles []*Collectible
  Generated    bool
}
```

#### World (Мир):
```go
type World struct {
  Chunks       map[int]*Chunk  // Активные чанки
  ActiveChunks []int           // Список активных
  Seed         int64           // Seed для RNG
  Rng          *rand.Rand
}
```

### 🎲 Процедурная генерация

### Алгоритм генерации чанка:

**1. Земля:**
```
80%: [████████████████] Сплошная
20%: [████]    [████]  С ямой
```

**2. Платформы (холмы):**
- Количество: 2-5
- Высота: 80-200px
- Ширина: 80-140px
- Тип: stone (70%), grassHalf (30%)

**3. Домики:**
- Шанс: 40% (если нет ямы)
- Тип: beige/dark/gray (33% каждый)
- Позиция: 0-300px по X

**4. Деревья:**
- Количество: 1-3
- Тип: pine (50%), oak (50%)
- Позиция: 0-350px по X

**5. Враги:**
- Шанс: 60% (если нет ямы)
- Тип: slime/snake/spider
- Патруль: ±60px

**6. Монетки:**
- Количество: 3-7
- Позиция: случайная высота

**7. Звёзды:**
- Шанс: 30%
- Позиция: 120-200px высоты

### 🗑️ Оптимизация памяти

#### Управление чанками:

**MaxChunks: 5**

```
Игрок: [●]
Чанки: [-2][-1][0][1][2]
        ↑           ↑
    Удаляется   Добавляется
```

**Алгоритм:**
```go
Update():
  chunkAhead = (cameraX + screenWidth) / chunkWidth
  GetChunk(chunkAhead + 1)  // Создать впереди
  
  if len(ActiveChunks) > MaxChunks:
    RemoveOldestChunk()  // Удалить сзади
```
