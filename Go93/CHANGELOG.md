### 🏗️ Архитектурные изменения

#### Удалена векторная графика:
```go
// БЫЛО:
vector.DrawFilledRect(screen, ...) // ❌

// СТАЛО:
screen.DrawImage(sprite, opts) // ✅
```

#### SpriteRenderer:
- **SetSprite()** - установка статичного спрайта
- **SetAnim()** - установка анимации
- **Update()** - обновление кадра
- **Draw()** - отрисовка с масштабированием

#### Масштабирование:
```go
opts.GeoM.Scale(
    transform.Width / float64(sprite.Bounds().Dx()),
    transform.Height / float64(sprite.Bounds().Dy())
)
```

### 🎮 Геймплей

#### Классический 2D-платформер:
- **Бег и прыжки** - слева направо
- **Двойной прыжок** - в воздухе
- **Сбор монеток** - +10 очков
- **Сбор звёзд** - +50 очков, цель уровня
- **Избегание врагов** - слизни, змеи, пауки

#### Уровни:
- **Домики** - 2 + level (3 типа)
- **Деревья** - 8 + level * 2 (сосны, дубы)
- **Монетки** - 15 + level * 3
- **Звёзды** - 5 + level
- **Враги** - 3 + level
