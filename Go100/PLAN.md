# 📅 День 100 - 10 апреля 2026 г.
## 🎮 Проект: Match-3 "Три в ряд"

### 🎯 Цель дня
Создать с нуля кросс-платформенную игру "Три в ряд" на Go + Ebitengine

### 📋 План разработки
1. **Базовая архитектура** - инициализация проекта, структура папок
2. **Игровое поле** - сетка 8x8, система спрайтов из папки sprites
3. **Механика матчей** - поиск 3+ в ряд, удаление, начисление очков
4. **Анимации** - плавное падение, эффекты уничтожения
5. **UI** - счёт, меню, game over экран
6. **Кросс-платформа** - Windows, Web (WASM), Mobile, Telegram Apps

### 🛠 Технологии
- **Язык**: Go 1.25+
- **Движок**: Ebitengine v2.9+
- **Спрайты**: D:\Projects\sprites\
- **Цель**: Освоение Go через практику геймдева

### 🎯 Долгосрочные цели
- Продвинутый уровень Go
- Успешное собеседование на Go-разработчика
- Портфолио из нескольких законченных проектов
