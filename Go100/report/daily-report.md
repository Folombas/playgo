#### Реализованная механика v2.0

1. **Классический Match-3**:
   - Поле 8x10 клеток (увеличено с 8x8)
   - 8 типов кристаллов (красный, синий, зелёный, жёлтый, фиолетовый, оранжевый, голубой, розовый)
   - Выделение кликом, обмен с соседними
   - Автоматическое обнаружение совпадений (3+ в ряд)
   - Удаление совпавших + гравитация + новые сверху
   - Каскадные реакции (combo system)

2. **Спецэлементы**:
   - 4 в ряд = 💣 Бомба (взрывает область 3x3)
   - 5 в ряд = 🌈 Радужный кристалл (уничтожает все камни одного типа)
   - L/T форма = Луч (уничтожает всю линию/колонку)

3. **Анимации**:
   - Плавное перемещение кристаллов (lerp 0.2)
   - Анимация исчезновения (scale + alpha fade)
   - Падение новых кристаллов сверху
   - Система частиц при уничтожении
   - Screen shake для комбо 3+

4. **Визуальные эффекты**:
   - Звёздное небо на фоне (100 звёзд)
   - 8 цветных кристаллов с формами (diamond, polygon, rectangle, square, cube)
   - Подсветка выбранного кристалла
   - Частицы разных цветов при взрывах
   - Всплывающие очки (+points)
   - Градиентные панели UI

5. **UI/UX**:
   - Главное меню с анимацией
   - Панель счёта (очки, цель, комбо, ходы)
   - Красивые кнопки (ИГРАТЬ, ВЫЙТИ, ПАУЗА, НАЗАД)
   - Title bar с названием игры
   - Hover-эффекты на кнопках

6. **Шрифты**:
   - Попытка загрузки BoldPixels (pixel font)
   - Fallback на debug print если шрифт не найден

#### Управление

- **Повторный клик**: Отменить выделение
- **Кнопки**: Навигация по меню
