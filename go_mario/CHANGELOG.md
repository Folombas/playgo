# Changelog

Все изменения в проекте Go Mario.

## [1.0.0] - 2026-03-27 (День 87)

### Полная переработка с нуля

#### Добавлено
- **Новая архитектура проекта**:
  - Модульная структура с разделением на пакеты
  - `internal/assets` - система загрузки ассетов
  - `internal/player` - сущность игрока
  - `internal/level` - генерация и управление уровнем
  - `internal/game` - основная игровая логика

- **Игрок**:
  - Плавное движение влево/вправо
  - Прыжок с гравитацией
  - Анимации: idle, walk, jump, duck, hurt
  - Система жизней и неуязвимости
  - Сбор монет с подсчётом очков

- **Уровень**:
  - Процедурная генерация 100x16 тайлов
  - Разные типы тайлов (трава, земля, кирпичи, блоки)
  - Платформы различной длины
  - Блоки с предметами (question blocks)

- **Враги**:
  - Slime - наземные враги
  - Fly - летающие враги
  - Простой AI с патрулированием
  - Механика уничтожения прыжком сверху

- **Предметы**:
  - 3 типа монет (бронза, серебро, золото)
  - Грибы и звёзды (заготовлены)
  - Флаг завершения уровня

- **Декорации**:
  - Облака на небе
  - Кусты на земле
  - Растения

- **UI**:
  - Счёт игрока
  - Счётчик монет
  - Жизни
  - Номер мира и уровня

- **Система**:
  - 3 мира по 3 уровня
  - Экран победы после прохождения
  - Экран проигрыша
  - Меню с инструкциями

#### Изменено
- Полностью переписан код с нуля
- Удалён старый сложный код
- Упрощена архитектура для лучшего понимания

#### Технические детали
- Go 1.25
- Ebitengine v2.9.9
- Platformer Complete Pack (Kenney.nl)
