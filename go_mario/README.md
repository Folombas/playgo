# 🍄 Go Mario v1.0.0

**2D Platformer** — Классический платформер в процессе полной переработки!

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| `←` / `A` | Движение влево |
| `→` / `D` | Движение вправо |
| `Пробел` / `W` | Прыжок |
| `↓` / `S` | Приседание |
| `Enter` | Выбор в меню |

## 🎯 Особенности

### Игрок
- Плавное движение и прыжки
- Анимации: стояние, бег, прыжок, приседание, получение урона
- Система жизней (3 жизни)
- Неуязвимость после получения урона

### Враги
- **Slime** - наземные враги, патрулируют территорию
- **Fly** - летающие враги
- Механика: прыгай сверху чтобы убить, избегай касаний сбоку

### Предметы
- 🪙 **Монеты** (бронза, серебро, золото) - увеличивают счёт
- 🍄 **Грибы** - power-up (в разработке)
- ⭐ **Звёзды** - супер-сила (в разработке)
- 🚩 **Флаг** - завершение уровня

### Уровень
- Процедурная генерация уровня
- Разнообразные тайлы (трава, земля, кирпичи, блоки с предметами)
- Декорации (облака, кусты, растения)
- 3 мира по 3 уровня в каждом

## 🛠️ Технологии

- **Go 1.25** — язык программирования
- **Ebitengine v2.9.9** — игровой движок
- **Platformer Complete Pack** — спрайты от Kenney.nl

## 🚀 Запуск

```bash
cd go_mario
go mod tidy
go run main.go
```

### Отладочный режим

```bash
go run main.go -debug
```

### Показать версию

```bash
go run main.go -version
```
