# 🍄 Go Mario v2.0.0

**2D Platformer** — Простая и стабильная версия Mario на Go!

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| `←` / `A` | Движение влево |
| `→` / `D` | Движение вправо |
| `Пробел` / `↑` | Прыжок |
| `Enter` | Выбор в меню |

## 🎯 Особенности

- ✅ Простой и понятный код
- ✅ Стабильная работа без багов
- ✅ Плавная камера
- ✅ Враги (Slime)
- ✅ Монеты для сбора
- ✅ Система жизней
- ✅ Победа в конце уровня

## 🚀 Запуск

```bash
cd go_mario
go run main.go
```

## 📊 Структура

Весь код в одном файле `main.go` для простоты и надёжности.

## 🎮 Геймплей

- Доберись до флага в конце уровня
- Прыгай на врагов сверху чтобы убить их
- Собирай монеты для очков
- Избегай падения в пропасть
