# Go Mario — 2D Platformer

Классический 2D-платформер в стиле Super Mario Bros, написанный на Go с использованием движка Ebitengine.

## 🎮 Особенности

- 🌤️ Голубое небо с белыми облаками
- ☀️ Жёлтое солнце с лучами
- 🌱 Зелёная земля с травой
- 🎨 Пиксель-арт стиль
- 💥 Комбо-система с множителями очков
- 🔴 Пружины для высоких прыжков
- 🌀 Телепорты для быстрого перемещения
- 🗝️ Ключи и сундуки с сокровищами
- ⚠️ Шипы и другие опасности
- 🏆 Система достижений
- 👾 13 типов врагов с уникальным поведением

## 🚀 Запуск

```bash
cd go_mario
go run main.go
```

Или запустить скомпилированный бинарник:

```bash
./go_mario
```

## 🎯 Управление

| Клавиша | Действие |
|---------|----------|
| ←/A | Движение влево |
| →/D | Движение вправо |
| ↑/W/SPACE | Прыжок |

## 🎯 Игровые механики

### Комбо-система
- Прыгайте на врагах подряд для построения комбо
- Максимальное комбо: x10
- Множитель очков: 1x + 0.5x за каждый уровень комбо
- Таймер комбо: 2 секунды между уничтожениями врагов

### Пружины
- 🔴 Красные: обычные пружины (мир 1)
- 🟢 Зелёные: пружины мира 2+
- 🔵 Синие: пружины мира 4+
- Подбрасывают игрока высоко вверх

### Телепорты
- 🌀 Фиолетовый → Синий телепорт
- Мгновенное перемещение между точками уровня
- Появляются в мирах 2+

## 🛠️ Технологии

- **Язык:** Go 1.25
- **Движок:** Ebitengine v2.9.9
- **Размер окна:** 800×600 пикселей
- **Шрифт:** SuperAdorable (24pt)
- **Аудио:** Kenney RPG Audio

## 📝 Игровые объекты

### Небо
- Голубой фон (RGB 135, 206, 235)
- 4 белых пушистых облака
- Жёлтое солнце с лучами и свечением

### Земля
- Коричневый грунт (RGB 139, 69, 19)
- Зелёная трава (RGB 34, 139, 34)
- Детали травы (отдельные травинки)

### Враги (13 типов)
- 🟢 Goomba/Koopa — простые ходячие враги
- 🐝 Bee — летающие враги
- 🪰 Fly — летающие по синусоиде
- 🐸 Frog — прыгающие враги
- 🐭 Mouse — быстрые наземные враги
- ⚙️ Saw — движущиеся пилы (нельзя давить)
- 🐚 Barnacle — стационарные враги
- 🐞 Ladybug — летающие враги
- 🐌 Snail — бронированные улитки
- 🪱 Worm — враги, появляющиеся из земли
- 🐟 Fish — плавающие враги

### Бонусы
- 🍄 Гриб — увеличивает игрока
- 🌸 Цветок — огненная форма
- ⭐ Звезда — неуязвимость (10 сек)
- 🍄 1UP — дополнительная жизнь
