# 🍄 GO MARIO: CARD BATTLES 🍄

**Карточный Roguelike в стиле Slay the Spire**

Go365 Challenge - День 86 (26 марта 2026)

---

## 📖 Описание

**GO MARIO: CARD BATTLES** — это карточный roguelike где ты строишь колоду, сражаешься с врагами и поднимаешься по этажам!

**Жанр:** Card Game / Roguelike / Deckbuilder  
**Вдохновение:** Slay the Spire, Balatro

---

## 🎮 Геймплей

### Управление

| Клавиша/Действие | Описание |
|------------------|----------|
| Мышь | Выбор карт, навигация |
| Enter / Пробел | Подтверждение |
| Escape | Пропустить / Назад |

### Основные механики

- 🃏 **Колода** — начинайте с 8 карт (4 Удара, 4 Защиты)
- ⚡ **Энергия** — 3 энергии на ход для разыгрывания карт
- 🎴 **Рука** — 5 карт каждый ход
- 🛡️ **Блок** — временная защита
- ❤️ **HP** — здоровье, при потере всех HP — game over

## 🃏 Типы карт

### Атака (Attack) 🔴
Наносят урон врагам

| Карта | Стоимость | Урон | Эффект |
|-------|-----------|------|--------|
| Удар | 1 | 6 | Базовая атака |
| Сильный удар | 2 | 10 | Мощная атака |
| Критический удар | 1 | 8 | Убивает если у врага < 10 HP |
| Огненный шар | 2 | 12 | Урон всем врагам |
| Смертельный бросок | 1 | 15 | Получите 2 урона |

### Навык (Skill) 🔵
Защита и утилити

| Карта | Стоимость | Блок | Эффект |
|-------|-----------|------|--------|
| Защита | 1 | 5 | Базовая защита |
| Сильная защита | 2 | 12 | Много блока |
| Уклонение | 1 | 8 | + Возьмите 1 карту |
| Медитация | 0 | 0 | +2 энергии |
| Исцеление | 1 | 0 | +8 HP |

### Сила (Power) 🟣
Пассивные бонусы

| Карта | Стоимость | Эффект |
|-------|-----------|--------|
| Ярость | 1 | +1 энергия каждый ход |
| Броня | 1 | +3 блок каждый ход |
| Сила | 2 | +2 к урону атак |
| Регенерация | 1 | +2 HP в конце хода |
| Концентрация | 1 | +1 карта каждый ход |

### Структуры данных

```go

    id, name, description
    cardType    // Attack, Skill, Power
    rarity      // Common, Uncommon, Rare
    cost, damage, block
}

type Player struct {
    health, block, energy
    deck, hand, discard
    strength, regen, extraDraw
}

type Enemy struct {
    name, health, damage
    intent, intentValue
}
```
