# 🍄 GO MARIO SURVIVOR 🍄

**Roguelite Survivor в стиле Vampire Survivors**

Go365 Challenge - День 86 (26 марта 2026)

---

## 📖 Описание

**GO MARIO SURVIVOR** — это roguelite survivor где ты играешь за Марио (Зелёного Пришельца) и должен выживать против бесконечных волн врагов!

**Жанр:** Roguelite / Survivor / Bullet Hell  
**Вдохновение:** Vampire Survivors

---

## 🎮 Геймплей

### Управление

| Клавиша | Действие |
|---------|----------|
| ← → ↑ ↓ / WASD | Движение |
| 1, 2, 3 | Выбор апгрейда при левел-апе |
| Enter | Старт / Рестарт |

### Особенности

- ⚔️ **Авто-атака** — оружие стреляет автоматически в ближайшего врага
- 📦 **Сбор опыта** — выпадающие из врагов кристаллы опыта
- 🎯 **Прокачка** — выбирай 1 из 3 случайных улучшений
- 🌊 **Волны врагов** — каждые 30 секунд новая волна
- 🔥 **Несколько оружий** — комбинируй разные типы атак

## 🎯 Игровые структуры

### Player
```go
type Player struct {
    x, y         float64    // Позиция
    health       int        // Здоровье
    level        int        // Уровень
    exp          int        // Опыт
    weapons      []*Weapon  // Оружия
    damageMult   float64    // Множитель урона
    attackSpeed  float64    // Скорость атаки
}
```

### Weapon
```go
type Weapon struct {
    wType      WeaponType   // Тип оружия
    damage     int          // Урон
    cooldown   int          // Перезарядка
    projectiles int         // Кол-во снарядов
    pierce     int          // Проникновение
    sizeMult   float64      // Множитель размера
}
```

### Enemy
```go
type Enemy struct {
    enemyType  int          // Тип врага
    health     int          // Здоровье
    speed      float64      // Скорость
    damage     int          // Урон
}
```
