# 🎮 HERO ADVENTURE v1.0.0

**Классический 2D платформер** на Go + Ebitengine!

## 🎯 Особенности

- ✅ **Простой и стабильный код** - никаких багов!
- ✅ **Земля с газоном** - классические платформы
- ✅ **Враги** - слизни, которые патрулируют уровень
- ✅ **Монеты** - собирай для очков
- ✅ **Флаг** - доберись до конца чтобы победить!

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| `←` / `A` | Движение влево |
| `→` / `D` | Движение вправо |
| `Пробел` / `↑` | Прыжок |
| `Enter` | Выбор в меню |

## 🚀 Запуск

```bash
cd go_mario
go run main.go
```

## 📊 Использованные спрайты

Из **Platformer Complete Pack**:
- ✅ Player (p1_stand, p1_walk, p1_jump)
- ✅ Tiles (grass, dirt, brick, box)
- ✅ Enemies (slimeWalk1, slimeWalk2)
- ✅ Items (coin, flag)
- ✅ Decorations (cloud, bush)
- ✅ Background (bg)

## 📝 Структура

Весь код в **ОДНОМ файле** `main.go` - просто и надёжно!
