# Go Mario 🍄

**2D Platformer на Go + Ebitengine**

Go365 Challenge - День 86 (26 марта 2026)

---

## 📖 Описание

Классический 2D-платформер в стиле Mario, написанный на языке Go с использованием движка Ebitengine.

**Главный герой:** Зелёный пришелец (Green Alien)  
**Цель:** Собрать монеты, победить врагов и добраться до флага!

---

## 🎮 Геймплей

### Управление

| Клавиша | Действие |
|---------|----------|
| ← → / A D | Движение влево/вправо |
| Пробел / ↑ / W | Прыжок |
| Enter | Подтверждение в меню |

### Механики

- **Прыжки на врагах** - прыгайте сверху на врагов, чтобы победить их
- **Сбор монет** - собирайте золотые монеты для очков
- **Вопросительные блоки** - ударяйте снизу для получения монет
- **Флаг победы** - доберитесь до конца уровня

## 🎯 Игровые объекты

### Игрок (Player)

```go
type Player struct {
    x, y      float64    // Позиция
    vx, vy    float64    // Скорость
    width     float32    // Шxрина
    height    float32    // Высота
    onGround  bool       // На земле?
    facing    int        // Направление
    animFrame int        // Кадр анимации
    
    // Статистика
    coins     int        // Монеты
    score     int        // Очки
    lives     int        // Жизни
}
```

### Враги (Enemies)

| Враг | Описание | Поведение |
|------|----------|-----------|
| 🟢 Slime Green | Зелёный слайм | Ходит влево-вправо |
| 🔵 Slime Blue | Синий слайм | Ходит быстрее |

### Тайлы (Tiles)

| Тип | Описание |
|-----|----------|

| 1 | Трава/земля |

| 3 | Вопросительный блок |
| 4 | Твёрдый блок |
| 5 | Труба |
