# 🍄 SUPER GO MARIO v3.0.0 - Ultimate Edition

**Крутой 2D-платформер** на Go + Ebitengine с боссами, power-ups и частицами!

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| `←` / `A` | Движение влево |
| `→` / `D` | Движение вправо |
| `Пробел` / `W` / `↑` | Прыжок |
| `Z` | Огненный шар (только с Flower) |
| `ESC` | Пауза |
| `Enter` | Выбор в меню |

## ✨ Особенности

### 🎯 Геймплей
- ✅ 3 мира по 3 уровня в каждом
- ✅ Боссы в конце каждого 3-го уровня
- ✅ Процедурная генерация уровней
- ✅ Ямы и платформы
- ✅ Флаг в конце уровня

### 🍄 Power-Up Система
- 🍄 **Гриб** - увеличивает здоровье (макс. 5 сердец)
- ⭐ **Звезда** - временная неуязвимость (10 секунд)
- 🌸 **Цветок** - возможность стрелять огненными шарами (клавиша Z)

### 👾 Враги
- **Slime** - наземные враги, патрулируют территорию
- **Fly** - летающие враги
- **Boss** - огромный босс с полоской здоровья и атаками

### 💎 Система очков
- Сбор монет (бронза=100, серебро=200, золото=300)
- Убийство врагов (200 очков)
- Комбо-множитель (до x50)
- Победа над боссом (1000 очков)
- High Score система

### 🎨 Эффекты
- Система частиц (сбор монет, убийство врагов, выстрелы)
- Тряска экрана при получении урона
- Мигание при неуязвимости
- Плавная камера

### ❤️ Жизни и здоровье
- 3 жизни по умолчанию
- Здоровье от 3 до 5 сердец (с грибами)
- Неуязвимость после получения урона (2 секунды)
- Смерть от падения в яму

## 🚀 Запуск

```bash
cd go_mario
go run main.go
```

## 🎯 Советы по игре

1. Прыгай на врагов сверху для комбо
2. Собирай грибы для увеличения здоровья
3. Используй звезды для прохождения опасных участков
4. Стреляй огненными шарами (Z) когда есть цветок
5. Избегай ям между платформами
6. Убивай боссов прыжками на голову
