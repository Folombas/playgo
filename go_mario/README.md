# 🚀 GO MARIO: SPACE ADVENTURE 🚀

**Космический шутер в стиле Geometry Wars / Asteroids**

Go365 Challenge - День 86 (26 марта 2026)

---

## 📖 Описание

**GO MARIO: SPACE ADVENTURE** — это динамичный космический шутер с неоновой графикой, волнами врагов, боссами и системой апгрейдов!

**Жанр:** Space Shooter / Arcade / Roguelite  
**Вдохновение:** Geometry Wars, Asteroids, Robotron

---

## 🎮 Геймплей

### Управление

| Клавиша | Действие |
|---------|----------|
| ← → / A D | Поворот корабля |
| ↑ / W | Тяга (двигатель) |
| Пробел / J / Z | Огонь |
| Shift / K | Рывок (dash) |
| Enter | Старт / Рестарт |

### Особенности

- 🚀 **Физика корабля** — инерция, тяга, трение
- ⚡ **Рывок** — уклонение от врагов
- 🔫 **Оружие** — авто-огонь с апгрейдами
- 📦 **Power-ups** — 5 типов бонусов
- 🌊 **Волны** — нарастающая сложность
- 👹 **Боссы** — каждые 5 волн

## 👹 Боссы

Каждые 5 волн появляется босс:

- **500+ HP** (растёт с волнами)
- **3 паттерна атаки:**
  - Spread shot (веер)
  - Circle shot (круг)
  - Aimed burst (залп)
- **2 фазы** (на 50% HP становится агрессивнее)

### Структуры данных

```go
type Player struct {
    x, y, angle    // Позиция и угол
    vx, vy         // Скорость
    health, shield // Здоровье и щит
    weaponLevel    // Уровень оружия
    multiShot      // Веерная стрельба
    homing         // Самонаведение
}

type Bullet struct {
    x, y, vx, vy   // Позиция и скорость
    damage         // Урон
    homing         // Самонаведение
}

type Enemy struct {
    enemyType      // 0: chaser, 1: shooter, 2: elite
    health, damage
}

type Boss struct {
    health, phase  // Фаза влияет на атаки
    pattern        // Текущий паттерн
}
```
