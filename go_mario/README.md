# 💠 SPACE WARRIOR v4.0.0

**Космический шутер-платформер** на Go + Ebitengine!

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| `←` / `A` | Движение влево |
| `→` / `D` | Движение вправо |
| `Пробел` / `W` / `↑` | Прыжок |
| `Z` | Атака оружием |
| `X` | Плазменный выстрел |
| `ESC` | Пауза |
| `Enter` | Выбор в меню |

## ✨ Особенности

### 🌌 Космическая тематика
- Тёмный фон с анимированными звёздами
- Технологичные каменные платформы
- Летающие враги-дроны
- Энергетические кристаллы вместо монет

### 🛡️ Система защиты
- **Щиты** вместо сердец (зелёные)
- **Энергетические кристаллы** для сбора
- **Силовые поля** от power-ups

### ⚔️ Оружие будущего
| Оружие | Описание |
|--------|----------|
| ⚡ **Energy Blade** | Ближний бой, энергетический меч |

| 💠 **Plasma** | Мощная плазменная пушка |

### 🚀 Power-Ups
- 🛡️ **Shield** - увеличивает защиту

## 🚀 Запуск

```bash
cd go_mario
go run main.go
```

## 🎯 Советы

1. Собирай кристаллы для очков
2. Открывай сундуки для получения оружия
3. Прыгай на врагов сверху для комбо
4. Используй плазму против боссов
5. Избегай красных снарядов босса
