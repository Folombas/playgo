### 2. Реализованные механики

#### 🏃 Паркур-система:
- Двойной прыжок
- Стена-ран (отталкивание от стен)
- Рывок (dash) в воздухе

#### 💻 Хакерство:
- Взлом терминалов (мини-игра с таймером)
- Отключение турелей
- Открытие электронных дверей
- Взлом дронов

#### 👤 Стелс:
- Индикатор видимости
- Шум от действий
- Тени для скрытия

#### 🔫 Бой:
- Энерго-пистолет (бесконечные патроны)
- Гранаты (ограничены)
- EMP-импульс (оглушает врагов)

### 3. Враги и ИИ

| Враг | Описание |
|------|----------|
| 🤖 Корпорат-солдат | Стреляет, патрулирует |
| 🛸 Дрон-камера | Обнаруживает, поднимает тревогу |
| 🔫 Турель | Стреляет при обнаружении |
| 🤖 Робот-охранник | Близкий бой, быстрый |
| 💀 Элитный солдат | Броня, гранатомёт |

### 4. Система тревоги

- Камеры обнаруживают игрока
- Солдаты бьют тревогу
- Уровень тревоги влияет на спавн врагов
- Максимальная тревога = больше врагов

### 7. Визуальный стиль

**Цветовая палитра:**
- Тёмно-синий/фиолетовый фон (ночной город)
- Неоновый голубой (#00FFFF) — интерфейсы, энергия
- Неоновый розовый (#FF00FF) — опасности, враги
- Неоновый зелёный (#00FF00) — хакерство, терминалы
- Оранжевый (#FFA500) — взрывы, частицы

### 8. Архитектура (ECS)

**Компоненты:**
- Transform — позиция, скорость
- Physics — гравитация, коллизии
- Health — здоровье, броня
- Energy — энергия для способностей
- Stealth — видимость, шум
- Hacker — уровень взлома
- SpriteRenderer — отрисовка
- Animator — анимации

**Сущности:**
- Player — KAI (игрок)
- Enemy — враги с ИИ
- Turret — турели
- Camera — камеры наблюдения
- Terminal — терминалы для взлома
- Door — двери (открываются ключом/взломом)
- Item — предметы
- Particle — эффекты

**Задача:**
1. Сбежать из нижних уровней города

## 🎮 Управление

| Клавиша | Действие |
|---------|----------|
| **A / ←** | Бежать влево |
| **D / →** | Бежать вправо |
| **W / ↑ / Пробел** | Прыжок (двойной!) |
| **S / ↓** | Присесть / стена-ран |
| **K** | Рывок (dash) |
| **J** | Выстрел из энерго-пистолета |
| **L** | Бросить гранату |
| **E** | Взлом терминала |
| **Q** | EMP-импульс |
| **ESC** | Пауза / меню |
