### 2. Полная переработка архитектуры игры

#### Новая концепция
**Было:** Добрый сказочный платформер про Солнышко ☀️
**Стало:** Мрачный киберпанк-платформер про хакера KAI 🌃

#### Сеттинг
- 2087 год, Нео-Токио
- Главный герой — элитный хакер-беглец
- Украл данные у мегакорпорации Zaibatsu Corp
- Цель — сбежать из города

#### Компонентная система (ECS)

**Компоненты:**
| Компонент | Описание |
|-----------|----------|
| **Transform** | Позиция, размер, скорость, направление |
| **Physics** | Гравитация (1200), трение (0.82), коллизии |
| **Health** | 100 HP, броня 0-100, неуязвимость |
| **Energy** | 100 энергия, регенерация 15/сек |
| **Stealth** | Видимость, шум, нахождение в тени |
| **Hacker** | Уровень взлома, скорость, прогресс |

**Сущности:**
| Сущность | Описание |
|----------|----------|
| **Player** | KAI — главный герой (32x48) |
| **Enemy** | 4 типа: Soldier, Drone, Robot, Elite |
| **Terminal** | Терминал для взлома (мини-игра) |
| **Door** | Электронная дверь (требует взлома) |
| **Item** | 6 типов: Health, Energy, Armor, Data, Grenade, EMP |
| **Camera** | Камера наблюдения (конус 60°) |
| **Turret** | Турель (дальность 300, урон 20) |

### 3. Новая игровая механика

#### 🏃 Паркур
- **Двойной прыжок** — второй прыжок в воздухе (слабее)
- **Wall slide** — замедление падения у стены
- **Wall jump** — отталкивание от стены
- **Dash (рывок)** — быстрый рывок (тратит 25 энергии)

#### 💻 Хакерство
- **Мини-игра** — движущаяся полоска
- **Зона взлома** — зелёная область (30-50%)
- **Прогресс** — накапливается при удержании E в зоне
- **Взлом** — открывает двери, отключает турели

#### 🔫 Бой
- **Энерго-пистолет** — бесконечные патроны, урон 15
- **Гранаты** — урон 50 по области, бросок по дуге
- **EMP-импульс** — оглушает врагов на 3 сек, отключает турели на 5 сек

#### 👤 Стелс (базовый)
- **Камеры** — обнаруживают в конусе 60°, дальность 250
- **Турели** — стреляют при обнаружении (дальность 280)
- **Тревога** — уровень alertness

### 4. Процедурная генерация уровней

**Параметры:**
- Ширина: 2000 + level*500
- Высота: 600
- Пол с ямами (случайные разрывы 80-160px)
- Платформы: 5+level*2
- Стены для wall run
- Враги: 3+level (типы зависят от уровня)
- Двери+терминалы: 1+level/2
- Предметы: 8+level*2
- Камеры: 2+level/2
- Турели: 1+level/3

### 5. Визуальный стиль

#### Цветовая палитра
- **Фон:** Тёмно-синий/фиолетовый градиент
- **Неон:** Голубой (#00FFFF), розовый (#FF00FF), зелёный (#00FF00)
- **Игрок:** Тёмная куртка с голубой неоновой полоской
- **Враги:** Серые, красные, фиолетовые тона

#### Фон
- Градиентное небо (киберпанк)
- Силуэт города с параллаксом (0.3x)
- Здания с мигающими окнами

#### Эффекты
- **Частицы** — при прыжках, выстрелах, взрывах, взломе
- **Трейл** — след от рывка (3 полупрозрачных копии)
- **Мигание** — при получении урона (1.5 сек)

### 6. Игровые состояния

1. **StateMenu** — главное меню
2. **StatePlaying** — игровой процесс
3. **StateHacking** — мини-игра взлома
4. **StatePaused** — пауза
5. **StateGameOver** — смерть игрока
6. **StateVictory** — уровень пройден

### 7. HUD (Интерфейс)

- **HP** — Зелёная полоска (200px)

- **ARM** — Серая полоска брони (200px)
- **DATA** — Счётчик данных (цель: 100)
- **SCORE** — Очки
- **GRENADES** — Количество гранат
- **EMP** — Количество EMP-зарядов
- **LEVEL** — Номер уровня
